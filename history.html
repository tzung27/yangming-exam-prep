臺灣的原住民族

必考從考古看史前文化，再認識今天的原住民族（南島語族、16 族、社會組織、正名）。
主題
史前文化分期、南島語族、原住民族分類與文化、平埔族群
重要遺址
長濱、左鎮人、大坌坑、圓山、芝山岩、植物園、卑南、十三行
重要觀念
分期看「工具與生計」；「出臺灣說」是學說不是定論；「正名」＝族群主體性

章節內容

  • 史前文化：舊石器（打製石器、無陶器、採集漁獵）→ 新石器（陶器、磨製石器、農業定居）→ 金屬器（煉鐵、對外貿易）。
  • 南島語族：臺灣原住民族語言皆屬南島語系，臺灣語言歧異度高，故有學者主張臺灣是南島語族原鄉。
  • 原住民族：今官方認定 16 族，社會組織各有特色（母系、階級、會所、年齡階級）。
  • 平埔族群：最早與外來者接觸，土地流失、漢化，近年推動正名與文化復振。

圖解：史前文化時間軸

  1. 舊石器長濱文化（臺東八仙洞）、左鎮人化石
  2. 新石器早大坌坑文化：粗繩紋陶
  3. 新石器中晚圓山（貝塚）、芝山岩（彩陶、稻米）、植物園（方格印紋陶）、卑南（石板棺、玉器）
  4. 金屬器十三行文化：煉鐵、外來錢幣與琉璃珠
  5. 歷史時代17 世紀起有文字紀錄（荷蘭、西班牙）

圖解：南島語族「出臺灣說」（學者推測）

  1. 臺灣語言歧異度最高，被推測為原鄉
  2. 菲律賓約數千年前向南擴散
  3. 印尼、馬來西亞東南亞島嶼
  4. 大洋洲／馬達加斯加東至復活節島、南至紐西蘭、西至馬達加斯加

證據：語言學（歧異度）、考古學（陶器分布）、遺傳學（DNA）。另有「起源於中國東南沿海」「起源於東南亞島嶼」等說法。

與他者互動下的原住民族

必考每個外來政權來到臺灣，對原住民採取不同的控制、隔離或同化方式，原住民族在戰後走向權利伸張。
主題
荷西、鄭氏、清、日治、戰後的原住民政策；原住民族運動
重要人物
沈葆楨、劉銘傳、佐久間左馬太、莫那魯道
重要事件
麻豆社事件、朱一貴事件、林爽文事件、牡丹社事件、太魯閣戰役、霧社事件、還我土地運動

章節內容

  • 荷蘭：武力征服→地方會議授藤杖、贌社、傳教與羅馬字（新港文書）。西班牙：北部傳教。
  • 鄭氏：屯田開墾侵入原住民土地，鎮壓大肚社群等反抗。
  • 清：前期劃界封山、土牛溝、隘制、番屯（消極隔離）；牡丹社事件後開山撫番（積極控制）。
  • 日治：隘勇線、五年理蕃計畫（武力）→ 霧社事件後同化、集團移住、高砂族。
  • 戰後：山地平地化（同化）→ 1980 年代原住民族運動：正名、還我土地、原住民族基本法。

圖解：各政權原住民政策演變

  1. 荷蘭征服＋地方會議＋傳教
  2. 西班牙北部傳教、據點
  3. 鄭氏屯田侵墾、武力鎮壓
  4. 清劃界隔離 → 開山撫番
  5. 日治武力理蕃 → 同化
  6. 戰後山地平地化 → 原住民族運動

圖解：清代番界政策演變

  1. 1722朱一貴事件後「立石為界」，禁漢人越界
  2. 乾隆年間繪紅線、藍線；挖溝堆土成「土牛溝」
  3. 清中葉設隘、隘丁防守；民間隘墾（如金廣福）
  4. 約 1790林爽文事件後實施番屯，劃紫線
  5. 1875牡丹社事件後沈葆楨開山撫番，解除入山禁令
  6. 1886劉銘傳設撫墾局，管理番地事務

界線一再往山區移動 → 顯示禁令擋不住移民開墾。

政權主要做法目的關鍵字

2-1

大航海～日治的遷徙與移動

必考臺灣被捲入世界貿易後，漢人、日本人等陸續移入，各政權對移民的態度決定人口結構。
主題
大航海時代、荷西經營、鄭氏屯田、清代渡臺禁令與分類械鬥、開港、日治移民村與華工
重要人物
鄭成功、鄭經、施琅、沈葆楨、劉銘傳
重要詞
熱蘭遮城、郭懷一事件、羅漢腳、頂下郊拚、吉野村、灣生

章節內容

  • 大航海時代：荷蘭據大員作轉口貿易並招募漢人來臺耕種；西班牙據北部。
  • 鄭氏：軍隊與眷屬來臺、屯田，漢人社會初步形成。
  • 清：渡臺禁令導致偷渡、男多女少、羅漢腳；閩粵移民分類械鬥；開港後茶、糖、樟腦帶來經濟機會；1875 解除渡臺禁令。
  • 日治：日本官吏商人移入、東部官營移民村；華工季節性來臺；臺灣人赴日留學、往中國與南洋移動。

圖解：移民時間軸

  1. 1624荷蘭占大員，招募漢人來臺
  2. 1626西班牙占雞籠，後至淡水
  3. 1662鄭氏取代荷蘭，軍民來臺屯田
  4. 1684清設臺灣府，實施渡臺禁令
  5. 1860 年代開港通商，洋行、傳教士來臺
  6. 1875解除渡臺禁令，鼓勵開墾後山
  7. 1895馬關條約，兩年國籍選擇
  8. 1910花蓮吉野村（官營移民村）

圖解：移民推拉力心智圖

為什麼移動？
推力（原鄉）
  • 閩粵人多地少
  • 明清之際戰亂
  • 日本國內人口壓力
拉力（臺灣）
  • 可開墾的平原土地
  • 荷蘭招募、提供耕牛農具
  • 開港後茶、糖、樟腦商機
政府態度
  • 荷蘭：招募
  • 鄭氏：帶來
  • 清初：限制 → 1875 開放
  • 日治：引進日本人、管制華工
影響
  • 男多女少、羅漢腳
  • 分類械鬥
  • 原住民土地流失
  • 東部日本化移民村

1-1 臺灣的原住民族（史前文化與南島語族）

一、史前文化怎麼分期？

沒有文字記錄的時代叫「史前時代」，靠考古遺址、出土器物（石器、陶器、骨器、金屬器）來重建。分期的關鍵在於「用什麼工具、怎麼取得食物」：

時代代表文化／遺址位置關鍵特徵（考點）
舊石器時代長濱文化臺東長濱 八仙洞臺灣目前已知最早的史前文化；打製石器、骨角器；沒有陶器、沒有農業，採集、狩獵、漁撈；住在海邊洞穴
左鎮人臺南左鎮 菜寮溪出土人類頭骨化石碎片，課本常稱臺灣已知最早的人類化石（年代約 2–3 萬年前，近年有重新測年的討論，依課本說法作答）
新石器時代早期大坌坑文化新北八里 等（分布全島沿海）粗繩紋陶；開始有陶器、可能有初期農業；多數學者認為與南島語族祖先有關

金屬器時代十三行文化新北八里 淡水河口會煉鐵（煉鐵作坊遺跡）；出土外來物品（如唐宋錢幣、銅器、琉璃珠）→ 與外界有貿易往來；人面陶罐、側身屈肢葬；與北部平埔族群（凱達格蘭）可能有關
核心觀念
  • 舊石器 → 新石器的分水嶺：陶器出現＋農業（定居）＋磨製石器。
  • 新石器 → 金屬器的分水嶺：會使用、甚至自己製造金屬器（鐵），並與外地交易。
  • 八里同時有大坌坑（新石器早期）和十三行（金屬器）——別因為地點一樣就搞混時代。
  • 史前文化不是「一個取代一個」，同一時期各地可能有不同文化並存。
易錯陷阱
  • 長濱文化沒有陶器。看到「繩紋陶」一定是新石器（大坌坑）。
  • 「石板棺＋玉器」＝卑南；「煉鐵＋外來錢幣」＝十三行；「貝塚」＝圓山。
  • 左鎮人是化石（人骨），不是「文化」；長濱是文化（器物）。

二、南島語族

  • 使用「南島語系」語言的族群，分布北起臺灣、南到紐西蘭，西起馬達加斯加、東到復活節島，是世界上分布最廣的語族之一。
  • 臺灣原住民族各族語言都屬南島語系，且語言歧異度高（語言差異大＝在這裡分化很久）。
  • 因此有學者提出「臺灣是南島語族原鄉（出臺灣說）」，也有其他說法（如起源於中國東南沿海或東南亞島嶼）。考題通常會寫「學者推測」——這是學說，不是定論。
  • 證據類型：語言學（語言歧異度）、考古學（大坌坑等陶器分布）、遺傳學（DNA）。

四、平埔族群與正名

  • 平埔族群：過去多居住在西部平原、北部、宜蘭平原，如凱達格蘭、噶瑪蘭、道卡斯、巴宰、拍瀑拉、巴布薩、洪雅、西拉雅等（分類方式不只一種）。
  • 因為最早與荷蘭人、漢人接觸，經歷土地流失、通婚、漢化，語言文化大量流失，許多人在日治戶籍中被登記為「熟」，戰後未被納入原住民身分。
  • 近年平埔族群正名運動：要求恢復身分、語言文化復振（如西拉雅的夜祭、噶瑪蘭正名成功）。
  • 「正名」的意義：由族人自己決定怎麼被稱呼，而不是由外人（清朝的「番」、日本的「蕃／高砂族」、戰後的「山胞」）命名 → 是族群主體性的展現。

1-2 與他者互動下的原住民族

這節的主軸：每個外來政權來到臺灣，都會面對原住民族，並發展出不同的「控制／治理／同化」方式。看懂政策的目的（要稅？要土地？要安全？要資源？）是答題關鍵。

一、荷蘭與西班牙時期（17 世紀）

  • 荷蘭（1624–1662，南部大員）：以武力征服反抗的村社（如麻豆社，1629 年麻豆社人殺害荷蘭士兵，荷蘭於 1635 年出兵征討），再以和約讓村社歸順。
  • 地方會議：召集歸順村社的長老，宣示效忠、授予藤杖（權杖）作為權力象徵 → 透過原有的村社領袖間接統治。
  • 贌社制度：荷蘭把與某村社的交易權公開標售（承包）給商人（多為漢人），商人獨占該社貿易（鹿皮等），荷蘭收取稅金。
  • 傳教與教育：傳教士以羅馬字拼寫西拉雅語（新港語），教導原住民讀寫 → 後來留下「新港文書」（番仔契）：原住民與漢人訂立的土地契約，荷蘭離開後仍使用到 19 世紀初。
  • 西班牙（1626–1642，北部雞籠、淡水）：也在北部傳播天主教，與北部原住民（如凱達格蘭族群）互動；1642 年被荷蘭驅逐。

二、鄭氏時期（1662–1683）

  • 實施屯田（軍屯），軍隊一邊駐守一邊開墾 → 今天的地名「新營、柳營、左營、林鳳營」等就是營盤田的痕跡。
  • 開墾範圍擴大，侵入原住民的獵場與土地，引發衝突，例如中部大肚社群（大肚王國）一帶的抗爭遭鄭氏軍隊鎮壓。

三、清治時期（1683–1895）：由「隔離」到「開山撫番」

措施時間背景內容與目的
劃界封山（番界）1721 年朱一貴事件後，1722 年起「立石為界」在漢人與生番之間劃界，禁止漢人越界私墾、也防止「亂民」躲入山區 → 目的是維持治安、減少衝突（隔離政策）
土牛溝（土牛紅線）乾隆年間挖溝、堆土成「土牛」作為界線的實體標記；地圖上以紅線、藍線等標示。界線隨開墾不斷往山區推移（顯示禁令擋不住移民）
隘制清中葉以後普遍在漢番交界設「隘」，雇用隘丁防守。有官隘、民隘；民間「隘墾」組織（如新竹北埔的金廣福）一面防守一面開墾 → 結果是漢人更深入山區
番屯1786–1788 林爽文事件中熟番協助清軍；1790 年前後實施仿四川屯練制度，挑選熟番（平埔族）組成屯丁，配給「養贍埔地」→ 讓熟番成為防守番界、維持治安的武力（以番制番）
開山撫番1874 年牡丹社事件（日本出兵恆春半島）後，1875 年沈葆楨推動開闢通往後山（東部）的道路、招撫原住民、解除渡臺禁令與入山禁令 → 由消極隔離轉為積極控制山地與東部，防止外國覬覦；劉銘傳時設撫墾局
  • 清代分類：熟番（歸化、納餉、服役）、生番（未歸化）、化番（介於兩者）。這是統治者的分類，以「是否接受統治」為標準，不是族群自稱。
  • 平埔族土地流失：漢人透過租佃、典賣、通婚取得土地；清廷設「番大租」制度想保障熟番收租權，但實際上熟番仍大量失去土地，部分族群集體遷徙（例：中部平埔族群於 19 世紀遷往埔里盆地；噶瑪蘭族南遷花蓮等）。
易錯陷阱

「番界」「土牛溝」不是為了保護原住民文化的善意政策，主要是清廷消極治臺、維持治安的手段；雖然客觀上有保留原住民土地的效果，但考題問「目的」時要選「防範漢人越墾、避免衝突與民變」。

四、日治時期（1895–1945）：理蕃政策

  • 日本視山地為「蕃地」，設為特別行政區，不適用一般法律，由警察管理（蕃地警察）。山地的樟腦、林木等資源是重要目標。
  • 初期以隘勇線逐步推進包圍山區（通電鐵絲網、砲台）。
  • 五年理蕃計畫（1910–1915，總督佐久間左馬太）：大規模武力討伐，1914 年太魯閣戰役為高峰；並沒收槍枝。
  • 霧社事件（1930）：賽德克族馬赫坡社頭目莫那魯道率族人於霧社公學校運動會襲擊日人；原因包括勞役剝削、文化壓迫（如禁止紋面、狩獵限制）、日警與原住民婦女婚姻問題等。日方以軍警鎮壓；1931 年又發生「第二次霧社事件」，倖存者被強制遷居川中島（今仁愛鄉清流部落）。
  • 事件後政策轉向同化、教化：蕃童教育所推行日語、集團移住（把部落從高山遷到較低處便於管理、改種水田）；1935 年起改稱「高砂族」；二戰時徵召「高砂義勇隊」。

五、戰後（1945–）：山地平地化 → 原住民族運動

  • 國民政府稱原住民為「山地同胞（山胞）」，推動山地平地化政策：1950 年代「山地人民生活改進運動」，推行說國語、改善生活（衣食住）、定耕農業等，目標是讓山地「與平地一致」→ 本質是同化。
  • 設山地保留地、山地管制；但隨著經濟發展，許多原住民移居都市從事勞力工作，土地流失、文化斷層。
  • 原住民族運動（1980 年代解嚴前後興起）：
    • 1984 年「臺灣原住民族權利促進會」（原權會）成立。
    • 1988 年起「還我土地運動」；同時期也有拆除吳鳳銅像、要求刪除課本吳鳳神話（1989 年吳鳳鄉改名阿里山鄉）。
    • 正名運動：1994 年修憲以「原住民」取代「山胞」；1997 年修憲改為「原住民族」（強調集體權）。1995 年起可恢復傳統姓名。
    • 1996 年成立中央部會「行政院原住民委員會」（2002 年更名原住民族委員會）。
    • 2005 年《原住民族基本法》公布：保障自治、土地、語言、文化、教育等權利。
    • 2016 年總統代表政府向原住民族道歉，成立轉型正義相關委員會。
核心觀念

一句話串起整節：荷蘭（征服＋間接統治＋傳教）→ 鄭氏（屯田侵墾）→ 清（隔離→開山撫番）→ 日治（武力理蕃→同化）→ 戰後（山地平地化同化）→ 原住民族運動（爭取正名、土地、自治）。名稱變化也是一條線：番 → 蕃／高砂族 → 山胞 → 原住民 → 原住民族。

2-1 大航海時代到日治時期的遷徙與移動

一、大航海時代：臺灣被捲入世界貿易

  • 16–17 世紀歐洲人東來，臺灣位於東亞貿易航線（中國、日本、東南亞之間）的要衝。
  • 荷蘭東印度公司：1622 年先占澎湖，被明朝驅逐，1624 年轉占大員（今臺南安平），建熱蘭遮城（後於赤崁建普羅民遮城）。以臺灣為轉口貿易據點（中國生絲、瓷器轉運日本、巴達維亞；臺灣輸出鹿皮、砂糖）。
  • 荷蘭招募漢人來臺耕種（稻米、甘蔗），提供耕牛、農具，課徵人頭稅等 → 漢人移民逐漸增加；1652 年漢人不滿重稅發生郭懷一事件。
  • 西班牙（1626–1642）：1626 年占雞籠（社寮島，今和平島）建聖薩爾瓦多城，後再到淡水建聖多明哥城；目的在保護馬尼拉—中國、日本航線、與荷蘭競爭；1642 年被荷蘭逐出。

二、鄭氏時期（1662–1683）

  • 1661 年鄭成功率軍登陸，1662 年荷蘭投降離臺；鄭成功同年病逝，由鄭經繼位。
  • 設承天府及天興、萬年二縣（後改州）；推行屯田，大批軍人、眷屬與移民來臺 → 漢人社會初步形成。
  • 1683 年清將施琅攻下澎湖，鄭克塽降清。

三、清治時期（1683–1895）

  • 1684 年臺灣納入版圖，設臺灣府（隸屬福建省）與臺灣、鳳山、諸羅三縣。
  • 渡臺禁令：清初對來臺有限制，一般整理為：來臺須申請許可（照單）、不准攜帶家眷、（有一說）粵地人民不准渡臺等；禁令時鬆時緊。結果：偷渡盛行（「六死三留一回頭」形容黑水溝之險）、男多女少、出現無家室無恆產的羅漢腳，成為社會不安來源。
  • 移民來源：主要是福建的泉州、漳州及廣東客家人。一般說法：泉州人多在沿海平原與港口、漳州人稍內陸、客家人多在丘陵台地（但分布受來臺先後、原鄉生活方式等多重因素影響，並非絕對）。
  • 分類械鬥：依祖籍（閩粵、漳泉）、姓氏、職業等分類爭奪土地、水源、商業利益而發生的武裝衝突，例如 1853 年艋舺「頂下郊拚」（泉州三邑人與同安人）。原因：移民社會、官府控制力弱、資源競爭、羅漢腳多。
  • 開港通商：1858 年《天津條約》、1860 年《北京條約》後，臺灣陸續開放淡水、雞籠、安平、打狗（1860 年代）→ 茶、糖、樟腦出口，洋行、傳教士（如馬偕在北部、馬雅各在南部）來臺。
  • 1874 牡丹社事件 → 1875 沈葆楨開山撫番，解除渡臺禁令，並鼓勵移民開墾東部（後山）。1885 年臺灣建省，劉銘傳為首任巡撫。

四、日治時期（1895–1945）的人口移動

  • 1895 年《馬關條約》：臺灣割讓日本；條約給臺灣住民兩年選擇國籍（期限 1897 年 5 月 8 日），逾期未離臺者視為日本臣民。
  • 日本人移入：
    • 官吏、軍警、商人、教師等多住在城市。
    • 官營移民村：總督府在人口較少、土地較多的東部（花蓮）設立移民村，如吉野村（1910，今花蓮吉安）、豐田村、林田村 → 目的：安置日本農民、緩解日本國內人口壓力、「日本化」東臺灣、鞏固統治。
    • 在臺出生的日本人俗稱「灣生」；戰後多被遣返日本。
  • 華工（中國勞工）：日本限制中國人來臺，須經申請許可；但因勞力需求，仍有許多華工來臺從事礦業、土木建築、茶業等工作，常是季節性、短期移動。
  • 臺灣人向外移動：赴日本留學；到中國（如廈門、福州）經商者稱「臺灣籍民」；戰時被動員至南洋（軍伕、志願兵等）。
  • 島內移動：西部人口往東部、往新興都市移動；原住民因集團移住被迫遷村。
核心觀念

判斷移民的「推力／拉力」：推力＝原鄉人口壓力、戰亂、謀生困難；拉力＝臺灣有可開墾土地、政府招募（荷蘭）、經濟機會（開港後的茶、樟腦）。政府的態度：荷蘭招募 → 鄭氏帶來 → 清初限制 → 1875 開放 → 日治引進日本人、管制華工。

史料

  • 史料：認識過去的材料，包括文字（檔案、日記、報紙、契約）、實物（器物、建築、遺址）、圖像、口述歷史、影音等。
  • 一手史料（原始史料）：與事件同時代、當事人或目擊者留下的（如當時的契約、日記、官方檔案、照片）。
  • 二手史料：後人根據其他史料整理、研究、詮釋的成果（如教科書、後人著作）。
  • 一手史料不一定比較可信，也可能有立場、誤記；要多方比對（史料考證）。

歷史解釋與多元觀點

  • 歷史事實 ≠ 歷史解釋：事實是發生了什麼；解釋是史家根據史料推論「為什麼、有何意義」，會受立場、時代、史料選擇影響。
  • 同一事件，不同群體（統治者／被統治者、漢人／原住民）的評價可能不同 → 多元觀點。
  • 誰的歷史：過去的歷史常以統治者、男性、菁英為中心；今天強調把原住民族、女性、庶民等「被忽略的人」納入。
  • 例：「開山撫番」從清廷角度是「開發」，從原住民角度是「失去土地與自主」。

題型解法套用

歷史題目看起來千變萬化，其實就五種套路。每一種都練一次「看題 → 判斷題型 → 抓關鍵字 → 刪去 → 作答」。

一、史料判讀題

  1. 先看題目問什麼（作者是誰？哪個時期？反映什麼現象？），再讀史料，帶著問題找答案。
  2. 圈出史料中的「時代線索」：人名、官名、地名、稱呼（番／蕃／山胞）、貨幣、制度名稱。
  3. 判斷出處與立場：寫的人是官員、傳教士、原住民、商人？立場會影響內容。
  4. 只根據史料推論：選項若說得比史料「更多、更絕對」（完全、一定、所有）通常是錯的。
範例

史料：「臺地向有番界，乃有民人偷越，私墾番地……應再於界上挖溝堆土，以示限制。」問：最可能是哪個時期？

線索「番界」「挖溝堆土」→ 土牛溝 → 清代（乾隆年間）。「番」字用法也指向清代（日治寫「蕃」）。

換你試試史料判讀
史料：「本會議召集各社長老，凡效忠公司者，各授藤杖一支，以為權柄之證。」此史料最可能出自哪一時期？
看答案與解析

答案：C

「公司」指荷蘭東印度公司，「各社長老」「藤杖」為地方會議特徵。

「公司」兩個字超關鍵：在這個範圍內，被稱為「公司」的統治者只有荷蘭東印度公司。

二、時序排列題

  1. 先貼政權標籤：史前／荷西／鄭／清／日治／戰後。
  2. 同一政權內再細排：清代記「前期隔離（番界 1722、番屯 1790）→ 後期開山撫番（1875）」；日治記「武力（1910 年代）→ 霧社（1930）→ 同化」。
  3. 找因果鏈：有「因為 A 所以 B」的一定 A 在前（牡丹社 → 開山撫番；林爽文 → 番屯）。
  4. 最後用選項驗證：先確定第一個和最後一個，選項通常就剩一兩個。
範例

排序：甲 番屯　乙 劃界封山　丙 開山撫番。→ 乙（1722，朱一貴後）→ 甲（約 1790，林爽文後）→ 丙（1875，牡丹社後）。

三、地圖／位置題

  1. 先確定地圖上標的是「北、中、南、東」哪一區，再想那一區有什麼代表遺址或據點。
  2. 用「位置＋特徵」雙重確認：例如北部有八里（大坌坑、十三行）兩個，要再用器物特徵區分。
  3. 外來勢力位置：荷蘭＝南（大員、赤崁）；西班牙＝北（雞籠、淡水）；日本移民村＝東（花蓮）；牡丹社事件＝南端恆春半島。
  4. 看有沒有「移動方向」：清代開墾由西部平原 → 丘陵 → 山區／後山；番界線隨時間往東推。
範例

地圖在臺灣東南部標示一個遺址，問特徵。→ 東南部（臺東）有長濱、卑南兩個 → 看選項：有「石板棺」選卑南、有「無陶器、洞穴」選長濱。

換你試試地圖題
地圖上標示了：甲 臺灣南端恆春半島、乙 臺灣東部花蓮平原、丙 臺灣北部雞籠、丁 臺南大員。下列配對何者正確？
看答案與解析

答案：D

大員是荷蘭據點（熱蘭遮城）。甲恆春半島為牡丹社事件地點；乙花蓮為日治官營移民村所在；丙雞籠為西班牙據點。

把四個地點與四件事各自配好：南端＝牡丹社，東部＝日本移民村，北部＝西班牙，臺南＝荷蘭。

四、因果推論題

  1. 確認題目問的是「原因」還是「影響」，畫底線。
  2. 把事件放回時間軸：原因一定在前、影響一定在後，時間不對直接刪。
  3. 找「最直接」的那一個：題目寫「最直接」「最主要」，要選緊接著的那一環，而不是遙遠的背景。
  4. 檢查邏輯方向：例如「禁止攜眷 → 男多女少」，選項若寫成「女多男少」就是方向反了。
範例

問：清廷 1875 年解除渡臺禁令的直接背景？→ 1874 牡丹社事件後，清廷要開發後山、增加人口以鞏固東部，所以鼓勵移民。開港（1860 年代）是更遠的背景，不是「最直接」。

換你試試因果推論
日治時期總督府在花蓮設立吉野村等官營移民村。下列何者不是其主要原因？
看答案與解析

答案：B

吉野村設立於 1910 年，戰後則是日本人被遣返，時間與因果皆不符。

時間檢查法：1910 年的事，原因不可能發生在 1945 年以後。

五、比較題

  1. 確定比較的對象與面向（例：清代 vs 日治，比「目的」還是「手段」？）。
  2. 畫一張迷你比較表：對象 × 面向，在腦中或試卷空白處填上關鍵字。
  3. 找「相同點」時要找兩者都成立的；找「相異點」時注意選項是否把兩者的特徵對調。
  4. 小心概括過度：「都是」「皆」的選項要兩邊都驗證。
範例

比較清代番屯與日治隘勇線：相同—都是控制山地、防範衝突的手段；相異—番屯利用熟番當武力（以番制番），隘勇線是日本以武裝警備線向山區推進包圍。

換你試試比較題
比較荷蘭時期與戰後初期政府對原住民的措施，下列敘述何者正確？
看答案與解析

答案：C

荷蘭傳教並以羅馬字教育原住民；戰後山地平地化推行國語、改善生活。A 番界為清代；B 內容對調；D 基本法為 2005 年。

B 是經典「對調陷阱」：兩件事都存在，但主詞被交換了。

小撇步
  • 遇到不熟的題目，先問自己：「這是哪個政權的事？」先定時代，答案常常就出來了。

三、常見失分原因

易錯陷阱
  • 史前文化地點搞混：八里有大坌坑和十三行；臺東有長濱和卑南。要用「器物特徵」區分。
  • 荷蘭、西班牙南北對調：荷南西北；西班牙是被荷蘭（不是鄭成功）趕走的。
  • 清代三大事件對應錯：朱一貴→番界；林爽文→番屯；牡丹社→開山撫番。
  • 政策目的答錯：清代番界是維持治安，不是保護文化；戰後山地平地化是同化，不是尊重多元。
