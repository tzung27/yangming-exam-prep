〈再別康橋〉題解

1928 年重遊英國劍橋（康橋），歸國途中寫成。康橋是作者的「精神故鄉」，全詩以輕柔的語調寫深刻的不捨，最後瀟灑告別。時間從夕陽寫到星輝，由黃昏走入夜晚。

課文段落結構（七節）

第 1 節
起：輕輕作別

「輕輕的」反覆出現，向西天雲彩告別，定下輕柔基調。

第 2–4 節
承：康河景物

金柳、青荇、榆蔭下的潭水，由岸上寫到水中；景中含情，願化為水草長留。

第 5 節
轉（高點）：撐篙尋夢

划船往青草更青處追夢，滿載星輝，興奮得想放歌。

第 6 節
轉（回落）：沉默

「但我不能放歌」，回到別離的現實，連夏蟲也沉默。

第 7 節
合：悄悄離去

與第 1 節首尾呼應（輕輕→悄悄），「不帶走一片雲彩」作結。

圖解：意象順序與情感變化

  1. 雲彩輕輕作別
    情：輕柔、不捨
  2. 金柳夕陽中的新娘
    情：心頭蕩漾
  3. 青荇甘心做水草
    情：深深眷戀
  4. 潭水彩虹似的夢
    情：沉入回憶
  5. 撐篙・星輝尋夢、想放歌
    情：最高點
  6. 笙簫・夏蟲不能放歌
    情：轉為沉默
  7. 揮袖不帶走雲彩
    情：瀟灑收束

〈斷章〉題解與結構

原是長詩中的片段，作者只留下四行，故名「斷章」。表面是畫面，實際談看與被看、裝飾與被裝飾的相對關係。

第 1 節
白天・看與被看

「你站在橋上看風景」：你看風景，同時也成了樓上之人眼中的風景。

第 2 節
夜晚・裝飾與被裝飾

明月裝飾你的窗，「你裝飾了別人的夢」：你被成全，也成全別人。

〈師說〉韓愈

必考一篇「論從師之道」的論說文：為什麼要有老師、該拜誰為師。
課文
〈師說〉
出處
《昌黎先生集》（韓愈文集，以課本題解為準）
文體
論說文；「說」體，說明事理、表達見解
寫作緣由
十七歲的李蟠不拘時俗向韓愈學習，韓愈作此文相贈
主旨
闡明從師學道的必要；擇師以「道」為標準，不論貴賤長少；批評士大夫恥於從師

作者簡介

時代唐代（768–824）
字號字退之；世稱韓昌黎、韓吏部；諡文，稱韓文公
流派古文運動領袖（與柳宗元並稱「韓柳」）；主張「文以明道」
代表作〈師說〉〈原道〉〈雜說〉〈祭十二郎文〉〈諫迎佛骨表〉
地位唐宋古文八大家之首；蘇軾稱其「文起八代之衰」

課文段落結構

第 1 段
立論：老師的功能與擇師標準

老師傳道、受業、解惑；人皆有惑，須從師；擇師只看「道」，不論貴賤長少。

第 2 段
駁論：批評恥於從師

以古今、子與身、百工與士大夫三組對比，批評時人「恥學於師」。

第 3 段
舉例：聖人無常師

孔子曾向郯子、萇弘、師襄、老聃請教，師生關係是相對的。

第 4 段
結論：寫作緣由

嘉許李蟠能行古道，作〈師說〉相贈。

圖解：論證結構

  1. 立論師者：傳道、受業、解惑
    道之所存，師之所存
  2. 駁論三組對比
    批評「恥學於師」
  3. 舉例孔子無常師
    聞道有先後
  4. 結論嘉許李蟠
    作師說以貽之
第二段三組對比
古 vs 今
  • 古之聖人：猶且從師
  • 今之眾人：恥學於師
  • → 聖益聖，愚益愚
子 vs 身
  • 為孩子擇師學句讀
  • 自己卻恥於從師
  • → 小學而大遺
百工 vs 士大夫
  • 巫醫樂師百工：不恥相師
  • 士大夫：群聚而笑
  • → 其可怪也歟

必背短句＋翻譯

短句白話
師者，所以傳道、受業、解惑也。老師，是用來傳授道理、教授學業、解答疑惑的人。
道之所存，師之所存也。道理在哪裡，老師就在哪裡。
聖益聖，愚益愚。聖人更加聖明，愚人更加愚昧。
小學而大遺。小的（句讀）學了，大的（解惑）反而放棄。
位卑則足羞，官盛則近諛。拜地位低的人為師覺得羞恥，拜官大的人為師又近乎諂媚。
聖人無常師。聖人沒有固定的老師。
聞道有先後，術業有專攻。懂得道理有早有晚，學問技藝各有專長。

一、〈再別康橋〉徐志摩

題解

短句修辭白話／賞析

二、〈斷章〉卞之琳

作者生平
  • 卞之琳（1910–2000），江蘇海門人。
  • 早年受新月派（徐志摩）賞識，後成為現代派重要詩人；與何其芳、李廣田合出《漢園集》，合稱「漢園三詩人」。
  • 也是翻譯家、莎士比亞研究者。
  • 詩作重知性、哲理、意象，含蓄凝練，受西方象徵主義影響。
題解

1935 年所作。原本是一首長詩中的片段，作者只留下這四行，所以叫「斷章」（斷片）。表面寫一幅畫面，背後談人與人、人與物之間「互為主客、相對而存在」的關係。

結構（兩節，各兩行）

  • 第一節：白天・橋上——「你站在橋上看風景，看風景人在樓上看你」。你是看風景的人（主體），同時也成了別人眼中的風景（客體）。修辭：頂真（看風景／看風景人）、映襯。
  • 第二節：夜晚・窗與夢——明月裝飾了你的窗子，而「你裝飾了別人的夢」。你被裝飾，也去裝飾別人。
核心觀念：相對性

看／被看、裝飾／被裝飾——同一個人同時是主體也是客體。世間萬物都在相對的關係中互相依存、互相成全。考題常問「本詩主旨」：答「人我相對、互為主客」，不是「愛情詩」、也不是「寫景詩」。

易錯陷阱

兩個「現代派」別搞混：卞之琳是 1930 年代中國大陸的現代派（以戴望舒、《現代》雜誌為核心）；臺灣的「現代派」是 1956 年紀弦成立，主張「新詩是橫的移植」。

  • 三歲喪父，由兄嫂撫養，刻苦自學。
  • 曾上〈諫迎佛骨表〉觸怒唐憲宗，被貶潮州刺史。
  • 與柳宗元倡導古文運動，「唐宋古文八大家」之首（並稱「韓柳」）。
  • 蘇軾稱他「文起八代之衰，道濟天下之溺」。
文學主張與風格
  • 反對六朝以來講究對仗、辭藻的駢文，主張恢復先秦兩漢的散文（古文）。
  • 主張「文以明道」（文章用來闡明儒家之道）、「惟陳言之務去」（不用陳腔濫調）。
  • 文風雄健奔放，氣勢磅礡，後人以「韓潮蘇海」形容韓愈、蘇軾的文章氣勢。

題解

「說」是論說文的一種，用來說明事理、表達見解。〈師說〉就是「論從師之道」。唐代士大夫以從師為恥，韓愈不顧流俗、收徒講學；當時十七歲的學生李蟠愛好古文、不受時俗拘束而向他學習，韓愈嘉許他能實踐古人從師之道，寫這篇文章送給他。

「師」字的詞性（超常考）
  • 名詞（老師）：古之學者必有「師」；「師」不必賢於弟子；巫醫樂「師」

L3〈鬼頭刀〉廖鴻基

作者生平
  • 廖鴻基（1957–），臺灣花蓮人。
  • 三十多歲起出海當討海人（漁夫），以親身海上經驗寫作。
  • 1990 年代組團隊在花蓮外海調查鯨豚，並發起成立黑潮海洋文教基金會，推動海洋保育與鯨豚觀察。
  • 代表作：《討海人》《鯨生鯨世》等。
海洋文學
  • 以海洋為題材，寫人與海的互動、海洋生態、海洋文化。
  • 臺灣代表作家：廖鴻基（漁人經驗、生態關懷）、夏曼・藍波安（蘭嶼達悟族，作品如《冷海情深》）。
  • 特色：親身經驗、寫實、生態意識、對生命的尊重。

題解與主旨

鬼頭刀是臺灣東部海域常見的大型洄游魚，頭部高而方、體色鮮豔（金黃、藍綠），性情兇猛，常在漂流物下聚集、追捕飛魚。作者以討海人的身分，記錄捕捉鬼頭刀的經驗：這種被漁人視為兇猛的魚，一尾上鉤後，同伴會緊跟著不肯離去，讓作者看到牠們的深情與生命尊嚴。文章由「捕魚的快感」轉向對生命的感動與反省，呈現人與海洋生物之間的複雜關係。

注意

本課為當代作品，課文細節（段落數、哪一尾先上鉤、船長說的話等）請以課本為準，這裡只整理主題與考點。

閱讀重點

  • 敘事觀點：第一人稱「我」，親身經歷，真實感強。
  • 描寫技巧：大量摹寫（視覺：魚體色彩的變化；聽覺、觸覺：拉扯釣線的力量），把搏鬥過程寫得緊張生動。
  • 情感轉折：獵捕者的興奮 → 看到生命情義的震撼 → 對殺生的不忍與省思。
  • 主旨：尊重海洋生命、反思人類對海洋的掠取；海洋不是只有「漁獲」，牠們也有情感與尊嚴。
  • 魚離水死去後，鮮豔色彩會迅速黯淡——常被拿來象徵生命的消逝。
易錯陷阱

主旨題的錯誤選項常寫成「歌頌漁獲豐收」「描寫漁民生活艱苦」「批評政府漁業政策」。抓住關鍵：生命的尊嚴與人的反省。

作者生平
  • 方苞（1668–1749），字鳳九，號靈皋，晚號望溪，世稱望溪先生，安徽桐城人。
  • 曾因戴名世《南山集》文字獄案受牽連下獄，後獲康熙赦免。
  • 桐城派初祖；與劉大櫆、姚鼐合稱「桐城三祖」。
  • 主張「義法」：義＝言有物（內容充實）；法＝言有序（結構條理）。文風雅潔。
人物背景
  • 左光斗（1575–1625），字遺直，桐城人，明熹宗時官左僉都御史，彈劾宦官魏忠賢，被誣下獄、受酷刑而死。後追諡「忠毅」。

題解

「逸事」即「軼事」：正史沒有記載、流傳於世的事蹟。本文屬傳記類散文，不寫左公一生，只挑選三件與史可法相關的小事，藉史可法來烘托左光斗。消息來源是作者的父親（先君子）與族中長輩塗山（左公的外甥），以示可信。

  • 側面烘托（襯托）：寫史可法的言行，來凸顯左公的識人與剛烈。

選篇 1：管寧割席（德行門）

短句白話翻譯
管寧、華歆共園中鋤菜，見地有片金。管寧和華歆一起在菜園鋤地，看見地上有一小塊金子。
管揮鋤與瓦石不異，華捉而擲去之。管寧照樣揮鋤，把金子看得和瓦片石頭一樣；華歆撿起來看了才丟掉。
有乘軒冕過門者，寧讀如故，歆廢書出看。有坐著華車、戴著禮帽的達官經過門口，管寧照常讀書，華歆丟下書跑出去看。
寧割席分坐，曰：「子非吾友也。」管寧割斷坐席分開坐，說：「你不是我的朋友。」

重點：用兩件小事（見金、看顯貴）對比兩人對財富與名位的態度；華歆「捉而擲去」代表他心有所動、只是勉強克制。軒冕（ㄒㄩㄢ ㄇㄧㄢˇ）：古代大夫的車子和禮帽，借代達官顯貴。成語「割席分坐／管寧割席」：比喻與朋友絕交。

選篇 2：華歆、王朗（德行門）

短句白話翻譯
華歆、王朗俱乘船避難，有一人欲依附，歆輒難之。華歆、王朗一起搭船逃難，有個人想搭船，華歆馬上表示為難。
朗曰：「幸尚寬，何為不可？」王朗說：「幸好船還寬敞，為什麼不可以？」
後賊追至，王欲捨所攜人。後來盜賊追上來，王朗想丟下那個帶上船的人。
既已納其自託，寧可以急相棄邪？既然已經接受他的託付，怎麼能因為情況危急就拋棄他？
世以此定華、王之優劣。世人因此評定華歆、王朗的高下。

重點：王朗一開始慷慨，危急時卻想拋棄人；華歆一開始謹慎，答應了就負責到底。結論：華歆優、王朗劣——重然諾、考慮後果、有始有終才是真正的德行。輒（ㄓㄜˊ）：就、立即。寧：豈、怎麼。

重點：陳太丘即陳寔（ㄕˊ），曾任太丘縣長；元方是他的兒子陳紀，當時七歲。元方以「無信、無禮」兩點駁斥，有理有據。字詞：期＝約定；舍＝通「捨」，捨棄；不＝通「否」；委＝丟下；引＝拉；顧＝回頭看。稱謂：尊君＝稱對方的父親（敬稱）；家君＝稱自己的父親（謙稱）。

國學常識必背清單

1. 文體：「說」體

核心觀念

「說」是論說文的一種，可議論、可說明，藉事物發揮道理，篇幅通常不長。常見篇章：

篇名作者朝代談什麼
〈師說〉韓愈唐從師之道
〈雜說四〉（世有伯樂）韓愈唐人才需要識者
〈捕蛇者說〉柳宗元唐苛政猛於虎
〈愛蓮說〉周敦頤北宋以蓮喻君子

跟「說」相近的論說文體還有「論」「辨」「原」（如韓愈〈原道〉）。

2. 唐代古文運動

項目內容

4. 逸事／傳記

逸事（軼事）

正史沒記載、散佚在外的事蹟。只選幾件小事，不寫完整一生；靠細節表現人物精神。例：〈左忠毅公逸事〉。

傳記

記人一生事蹟。正史列傳（如《史記》）、別傳、家傳、行狀、墓誌銘都屬傳記類。逸事可視為傳記的一種「補遺」。

(A) 名詞，老師。(B) 動詞，以之為師。(C) 「孔子師郯子」的第一個「師」是動詞（向……學習）；「師襄」是人名。(D) 「師道」是名詞，從師學習的風氣。(E) 動詞，從師學習。

三、修辭

第 7 題修辭L1・L4

(A) 轉化（擬人）。(B) 「目光如炬」：目光（本體）＋如（喻詞）＋炬（喻體），明喻。(C) 映襯、類疊。(D) 對偶、映襯。

題型解法套用

國文選擇題大多可以用「固定步驟」解。下面六種題型，每種都示範一次，再給你一題自己練。

1. 字音字形題

  1. 先掃一遍，圈出「眼熟但不確定」的字：通常是一字多音（讀、瞿、更）或形近字（炬／矩、攻／功）。
  2. 還原到課文語境：「句讀」是斷句，不是讀書 → ㄉㄡˋ；「瞿然」是驚視 → ㄐㄩˋ。
  3. 字形用字義檢查：「目光如炬」是火把（火部），「術業有專攻」是研究（攻打的攻）。
  4. 題目問「正確」還是「錯誤」？回頭再看一次題幹，再劃卡。
換你試試字音

支拄的「拄」念 ㄓㄨˇ（第三聲），柱子的「柱」才是 ㄓㄨˋ。

提手旁的拄＝用手撐著，第三聲；木字旁的柱＝柱子，第四聲。

2. 成語題

  1. 先確定成語本義：拆字解釋（目光／如／炬）。
  2. 判斷褒貶與對象：形容人？形容事？好還是壞？
  3. 代回句子讀一遍：語意通順、褒貶一致才對。
  4. 留意「望文生義」陷阱：如「不足掛齒」是不值一提，跟牙齒無關。
換你試試成語
下列「」內成語的使用，何者最恰當？
看答案與解析

答案：C

(A) 目光如炬是有見識，和馬虎矛盾。(B) 不恥下問是謙虛請教，與罵學生無關。(C) 詠絮之才稱讚女子才華，正確。(D) 割席分坐是絕交，與親密相反。

每個成語都先問自己「它原本在講什麼故事」，就不會用反。

3. 修辭判斷題

  1. 找「結構特徵」：有「像、如、是」連兩樣東西→譬喻；前尾接後頭→頂真；字詞重複→類疊；字數相等成對→對偶。
  2. 找「變身」：物有人的情感動作→擬人；人變成物→擬物。
  3. 找「代替」：用特徵、象徵物代替本名→借代（軒冕）。
  4. 一句可能有多種修辭：題目問的是哪一種就鎖定哪一種，不要被其他修辭干擾。
換你試試修辭
「位卑則足羞，官盛則近諛」主要使用哪一種修辭？
看答案與解析

答案：B

上下兩句都是五字，「位卑／官盛」「足羞／近諛」詞性相對，句法相同，為對偶（兼有映襯）。

數字數：5＋5，結構「名詞＋形容詞＋則＋副詞＋動詞」完全對稱，就是對偶。

4. 文言文閱讀（翻譯／文意）

  1. 先找主詞：文言文常省略主詞，問自己「這句是誰在做？」（例：「解貂覆生」＝左公解下貂裘蓋在書生身上）。
  2. 圈出關鍵虛詞與實詞：所以（用來）、庸（豈）、焉、乃、輒、寧（豈）。
  3. 處理特殊字：通同字（受→授、不→否）、詞性活用（師之、恥學）。
  4. 逐字翻再調語序：「句讀之不知」＝不知句讀（賓語前置）。
  5. 回扣上下文：選項若與前後文矛盾，一定錯。
換你試試文言翻譯
「既已納其自託，寧可以急相棄邪？」（華歆語）最恰當的翻譯是：
看答案與解析

答案：A

納：接受；自託：自己來託付；寧：豈、怎麼；以急：因為情況危急；邪：疑問語氣詞，同「耶」。

文言的「寧……邪？」常常是「怎麼能……呢？」的反問，不是現代的「寧可」。

5. 白話閱讀／新詩賞析

  1. 先抓意象：詩裡出現什麼景物？（金柳、青荇、雲彩；橋、樓、明月、窗、夢）
  2. 判斷情感基調：輕柔、不捨、哀傷、豪邁、哲思？從關鍵詞找（輕輕、悄悄、沉默）。
  3. 看結構：首尾呼應？前後對照？由景入情？
  4. 主旨題用「刪去法」：刪掉過度延伸（例：把〈斷章〉說成愛情詩）、只講一半（只寫景沒寫情）的選項。
換你試試新詩賞析
〈再別康橋〉末節以「悄悄的我走了」「不帶走一片雲彩」作結，最能表現作者何種心境？
看答案與解析

答案：D

全詩充滿對康橋景物的眷戀；結尾不帶走雲彩，是不驚擾、不帶走，把美好完整留在康橋，表現依戀而瀟灑的情感。

中間寫了那麼多美景，還說「甘心做一條水草」，怎麼可能是失望或無心留戀？所以只剩 D。

6. 國學常識題

  1. 先看朝代：很多錯誤選項是「時代錯置」（清朝的方苞放進唐宋八大家）。
  2. 再對「作者—流派—主張」三角：韓愈—古文運動—文以明道；方苞—桐城派—義法；徐志摩—新月派—三美。
  3. 注意一字之差：明道／載道、志人／志怪、門／卷。
  4. 數量題：唐 2＋宋 6＝八大家；桐城三祖；世說三十六門。
