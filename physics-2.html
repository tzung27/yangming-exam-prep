物質間的基本交互作用

複習第一次段考已考過萬有引力與庫侖定律；這次只要把四種交互作用的比較、強力與弱力抓穩。
課文/主題
重力、電磁力、強力、弱力的比較；日常生活中各種力的本質（內容以課本為準）
重要人物
牛頓（萬有引力）、庫侖（靜電力）、湯川秀樹（提出強作用的介子理論）
考法
強弱排序、作用範圍、哪些力屬於電磁力、β 衰變屬於哪種作用

章節內容

  • 強度：強力 ＞ 電磁力 ＞ 弱力 ＞ 重力；重力與電磁力作用範圍無限遠，強力與弱力只在原子核尺度內有效。
  • 日常接觸力——正向力、摩擦力、張力、彈力、浮力——本質上都是原子、分子間的電磁力。
  • 強力把質子、中子綁在原子核內；弱力造成 β 衰變（中子 → 質子 + 電子 + 反微中子）。
  • 天體運動由重力主導：天體幾乎電中性，電力互相抵消；重力只吸引、不會抵消。

對物體運動的研究歷程

必考從亞里斯多德的「重物落得快」到伽利略的實驗與數學；學會用位移、速度、加速度和兩種圖描述運動。
課文/主題
運動觀念的演進、運動的描述（位置、位移、速度、加速度）、等加速度運動、自由落體（內容以課本為準）
重要人物
亞里斯多德、伽利略
考法
平均速度 vs 平均速率、讀 x-t／v-t 圖、等加速度與自由落體計算、伽利略斜面 1:3:5:7

章節內容

  • 亞里斯多德：重的物體落得比較快；物體要持續運動必須持續受力（「力是維持運動的原因」）。靠思辨、沒有用實驗檢驗。
  • 伽利略：用斜面實驗「沖淡重力」，發現從靜止出發的距離與時間平方成正比（d ∝ t2），推論自由落體是等加速度運動；忽略空氣阻力時，輕重物體同時落地；提出「沒有外力，運動中的物體會一直運動下去」的慣性概念。
  • 描述運動：位移（向量，起點指向終點）≠ 路徑長（純量）；平均速度 = 位移 ÷ 時間，平均速率 = 路徑長 ÷ 時間；加速度 = 速度變化 ÷ 時間。
  • 圖形：x-t 圖的斜率 = 速度；v-t 圖的斜率 = 加速度、與時間軸圍成的面積 = 位移。

3-2

牛頓運動定律

必考力不是維持運動的原因，而是「改變運動狀態」的原因；三大定律一次搞懂。
課文/主題
慣性定律、運動定律（F = ma）、作用力與反作用力定律；重量、正向力、摩擦力（內容以課本為準）
重要人物
牛頓（1687《自然哲學的數學原理》）
考法
慣性實例判斷、合力與加速度同方向、作用力與反作用力 vs 平衡力、受力計算、電梯視重

章節內容

  • 第一定律（慣性定律）：物體所受合力為零時，靜者恆靜、動者沿直線等速運動。質量越大，慣性越大。
  • 第二定律（運動定律）：F合 = ma，加速度方向永遠與合力方向相同（但不一定與速度同向）。1 N = 1 kg·m/s2。
  • 第三定律（作用力與反作用力）：兩物體間的作用力與反作用力大小相等、方向相反、作用在不同物體上、同時產生同時消失、性質相同。
  • 重量 W = mg；1 kgw ≈ 9.8 N。電梯中磅秤讀的是正向力（視重），加速度向上讀數變大、向下變小。

圖解：三大定律

  1. 第一定律：慣性合力 = 0 → 速度不變（靜止或等速直線）
  2. 第二定律：F = ma合力 ≠ 0 → 產生加速度，方向同合力
  3. 第三定律：作用與反作用甲推乙，乙同時以等大反向的力推甲

電流的磁效應

必考1820 年厄斯特發現「電流會產生磁場」，電與磁第一次被連在一起；之後又發現磁場會對電流施力，做出了電動機。
課文/主題
磁鐵與磁場、磁力線、厄斯特實驗、載流導線（直導線、圓線圈、螺線管）的磁場、電磁鐵、載流導線在磁場中受力、電動機與揚聲器（內容以課本為準）
重要人物
厄斯特（電流磁效應，1820）、安培（電流間的磁力）
考法
用右手定則判斷磁場方向、羅盤偏轉、平行導線相吸相斥、電動機的能量轉換

章節內容

  • 磁力線：磁鐵外部由 N 極出發回到 S 極、內部由 S 到 N，形成封閉曲線；不相交；越密磁場越強；切線方向 = 該點磁場方向 = 小磁針 N 極所指方向。
  • 厄斯特實驗：導線通電，下方的羅盤偏轉 → 電流會產生磁場。
  • 長直導線：磁力線是以導線為圓心的同心圓；右手握導線、拇指指電流、四指彎曲方向 = 磁場方向。電流越大、離導線越近，磁場越強。
  • 圓線圈／螺線管：右手四指順著電流繞，拇指指向 N 極（管內磁場方向）。加鐵芯成為電磁鐵，斷電磁性就消失。
  • 磁場對電流施力：載流導線放在磁場中會受力（電流與磁場垂直時最大、平行時為 0）。平行導線：電流同向相吸、反向相斥。
  • 電動機（馬達）：電能 → 力學能；直流電動機用換向器每半圈改變線圈電流方向，才能持續同向轉動。揚聲器、電流計也是利用磁場對電流的力。

電磁感應

必考電能生磁，磁能不能生電？1831 年法拉第發現：只要通過線圈的磁力線數目「改變」，就會產生應電流。

章節內容

  • 產生應電流的條件：通過封閉線圈的磁通量（磁力線數目）發生變化。磁鐵靜止放在線圈裡、穩定直流電的磁場 → 沒有應電流。
  • 改變磁通量的方法：磁鐵與線圈相對運動、改變電流大小（開關接通／斷開瞬間）、改變線圈面積、轉動線圈（改變夾角）。
  • 法拉第感應定律：磁通量變化越快（變化率越大）、線圈匝數越多，應電動勢越大。
  • 冷次定律：應電流產生的磁場，總是反抗原磁通量的變化（增反減同、來拒去留）。這是能量守恆的結果——要產生電能就得付出力學能。

  • 變壓器：原線圈接交流電產生變化的磁場，副線圈感應出電壓；V1 : V2 = N1 : N2（理想變壓器，以課本為準）。可升壓也可降壓；接直流電無法變壓。

1. 運動觀念的演進

人物主張評價

3-2　牛頓運動定律

1. 第一定律：慣性定律

  • 內容：物體不受外力或所受合力為零時，靜者恆靜、動者恆沿直線做等速度運動。
  • 慣性：物體維持原來運動狀態的性質；質量是慣性大小的量度，與速度無關。
  • 生活實例：公車突然啟動人往後倒、急煞往前傾；抽桌布時碗盤留在原處；甩乾衣服上的水；鎚頭鬆了把鎚柄往地上撞；汽車安全帶、頭枕。

2. 第二定律：運動定律

牛頓第二運動定律
F合 = ma
F：合力（N）；m：質量（kg）；a：加速度（m/s2）。1 N = 1 kg·m/s2。加速度方向與合力方向相同。
  • 合力相同時，質量越大加速度越小（a ∝ 1/m）；質量相同時，a ∝ F。
  • 力改變的是速度（加速度），不是位置。合力變小但仍與速度同向 → 仍在加速，只是加速得比較慢。
  • 重量 W = mg；1 kgw = 1 kg × 9.8 m/s2 ≈ 9.8 N。質量不隨地點改變，重量會（月球上約為地球的 1/6）。

3. 第三定律：作用力與反作用力

  • 甲對乙施力，乙必同時對甲施一等大、反向、共線的力；兩力作用在不同物體，不能互相抵消。
  • 兩人在光滑冰面互推：受力大小一定相等；質量小的人加速度大（a甲 : a乙 = m乙 : m甲）。
  • 實例：游泳向後划水、人向前；火箭向下噴氣、火箭向上；走路時腳向後推地、地面摩擦力把人向前推；槍的後座力。
  • 「拔河贏的一方拉力比較大」✗——兩隊之間繩子的拉力相等；贏的一方是因為地面給他的摩擦力較大。

5. 解力學題的步驟

  1. 選定要分析的物體（一次一個）。
  2. 畫出它受的所有力：重力、接觸力（正向力、摩擦力、張力）、其他。不要畫它施給別人的力。
  3. 定正方向（通常取運動方向或加速度方向為正）。
  4. 求合力，代入 F合 = ma 求加速度。
  5. 再用運動學公式求速度、位移、時間。

6. 電梯與視重

人站在電梯內的磅秤上，磅秤讀數 = 磅秤對人的正向力 N。取向上為正：N − mg = ma → N = m(g + a)。看加速度方向，不看速度方向：加速上升與減速下降都是加速度向上，讀數都變大。

4-1　電流的磁效應

1. 磁鐵與磁場

  • 磁極成對出現，N 極與 S 極無法分離；同極相斥、異極相吸。
  • 小磁針（羅盤）N 極所指的方向 = 該點磁場方向。地理北極附近其實是地磁的 S 極，所以羅盤 N 極指北。
  • 磁力線性質：外部 N → S、內部 S → N，是封閉曲線；彼此不相交；越密磁場越強；切線方向為磁場方向。
  • 磁場的 SI 單位是特斯拉（T），1 T = 1 N/(A·m)（以課本為準）。

2. 厄斯特實驗（1820）

厄斯特在上課示範時發現：導線通電，旁邊的磁針會偏轉；電流反向，磁針偏轉方向也相反 → 電流會產生磁場。這是人類第一次發現電與磁的關聯。之後安培發現兩條載流導線之間也有磁力。

3. 載流導線產生的磁場

導線形狀磁力線形狀方向判斷強度與什麼有關
長直導線以導線為圓心的同心圓右手拇指 = 電流，四指 = 磁場電流越大、離導線越近越強（B ∝ I/r，以課本為準）
圓形線圈中心處近似直線四指 = 電流，拇指 = 中心磁場電流越大、匝數越多、半徑越小越強
螺線管外部像條形磁鐵，內部近似均勻四指 = 電流，拇指 = N 極電流越大、單位長度匝數越多越強；加鐵芯更強

羅盤題範例：導線南北向放在羅盤正上方，電流由南往北。在導線下方，右手拇指朝北，四指在導線下方由東往西繞 → 磁場向西 → 羅盤 N 極向西偏。若羅盤放在導線上方則向東偏。

4. 磁場對電流的作用

  • 載流導線在磁場中受力：電流與磁場垂直時最大，平行時為零；電流或磁場反向，力也反向。
  • 力的方向同時垂直於電流與磁場；判斷方法依課本的右手開掌定則（拇指電流、四指磁場、掌心為受力方向）。
  • 兩平行長直導線：電流同向相吸、反向相斥（與電荷的「同性相斥」相反）。
  • 運動中的帶電粒子在磁場中也會受磁力（電流就是電荷在流動），磁力與速度垂直，只改變方向不改變速率（是否列入以課本為準）。

5. 應用

裝置構造與原理
直流電動機線圈置於磁場中，兩邊受力方向相反形成力矩而轉動；換向器每轉半圈把電流方向反過來，使線圈持續同向轉動。電能 → 力學能。
揚聲器音訊電流（強弱、方向不斷改變）通過磁鐵旁的線圈 → 線圈受力忽前忽後 → 帶動紙盆振動發聲。把磁極 N、S 互換仍可發聲（只是振動相位相反）。
電磁鐵螺線管加軟鐵芯；通電有磁性、斷電即消失，可用電流大小控制磁性強弱。電鈴、磁浮列車、廢鐵起重機。

4-2　電磁感應

1. 法拉第的發現（1831）

既然電能生磁，法拉第就想「磁能不能生電」。他發現：把磁鐵插入或抽出線圈、或在鐵環一邊的線圈接通／切斷電流時，另一邊的線圈會出現短暫的電流；磁鐵靜止不動時則沒有。結論：變化的磁場才會產生電流，這個電流稱為應電流（感應電流），推動它的電壓稱為應電動勢。

2. 磁通量與產生應電流的條件

  • 磁通量 Φ：可以想成「穿過線圈面的磁力線數目」，與磁場強弱、線圈面積、線圈面與磁場的夾角有關（線圈面與磁場垂直時最多、平行時為零）。
  • 只要封閉線圈內的磁通量改變，就會產生應電流；線圈不封閉時只有應電動勢、沒有電流。
  • 法拉第定律：應電動勢的大小與磁通量的變化率成正比，也與線圈匝數成正比 → 磁鐵插得越快、線圈繞越多圈，電流越大。

3. 冷次定律：判斷應電流方向

核心觀念

應電流所產生的磁場，總是要反抗原來磁通量的變化：磁通量增加 → 應電流的磁場與原磁場反向；磁通量減少 → 與原磁場同向（增反減同）。從力的角度：磁鐵靠近時線圈排斥它，遠離時線圈吸引它（來拒去留）。

  1. 找出原磁場穿過線圈的方向。
  2. 判斷磁通量是增加還是減少。
  3. 增加 → 應電流磁場反向；減少 → 同向。
  4. 用右手（拇指指應電流的磁場方向）四指彎曲的方向就是應電流方向。

為什麼一定是「反抗」？若應電流的磁場反而「幫忙」變化，磁鐵就會被越吸越快、電流越來越大，憑空產生能量，違反能量守恆。所以要得到電能，就必須克服阻力做功：發電機轉起來會變「重」，磁鐵在銅管或鋁管中下落會變慢。

4. 發電機與交流電

  • 發電機：外力（水力、風力、蒸汽）轉動磁場中的線圈，通過線圈的磁通量週期性變化 → 產生大小、方向週期性改變的交流電。力學能 → 電能。
  • 臺灣家用交流電頻率為 60 Hz、電壓 110 V（或 220 V）。
  • 電動機與發電機構造相似、作用相反：電動機「電 → 動」，發電機「動 → 電」。

5. 變壓器

  • 構造：兩組線圈繞在同一個鐵芯上；原線圈接交流電產生不斷變化的磁場，鐵芯把磁力線導到副線圈，副線圈的磁通量跟著變化而感應出電壓。
  • 理想變壓器：V1/V2 = N1/N2，副線圈匝數多就升壓、少就降壓（是否計算以課本為準）。
  • 接直流電無法變壓：穩定電流產生的磁場不變，副線圈沒有磁通量變化（只有接通、切斷的瞬間有）。
  • 遠距離輸電用高壓：電流較小，導線發熱損耗較少；到用戶端再降壓。

6. 生活應用

應用怎麼用到電磁感應
電磁爐線圈通高頻交流電 → 變化磁場在鍋底感應出渦電流 → 鍋底發熱。需用鐵製等導磁鍋具（以課本為準）；陶瓷、玻璃鍋不能用。
無線充電充電板線圈通交流電 → 手機內線圈磁通量變化 → 感應電流 → 整流成直流充電。兩線圈距離太遠或沒對齊，效率變差。
悠遊卡、門禁感應卡讀卡機發出變化磁場，卡片內線圈感應出電流驅動晶片。
動圈式麥克風聲波推動振膜與線圈在磁鐵旁振動 → 感應電流。（揚聲器反過來用）
電吉他拾音器鋼弦振動改變拾音器線圈的磁通量。
金屬探測門變化磁場在金屬物體內感應出渦電流，渦電流的磁場再被偵測到。
手搖／搖晃式手電筒磁鐵在線圈中來回穿梭 → 應電流（交流）→ 整流儲存。
易錯陷阱
  • 「電磁感應是厄斯特發現的」✗——厄斯特是電流磁效應，法拉第才是電磁感應。
  • 「穩定的磁場可以產生穩定的應電流」✗——一定要變化。
  • 「揚聲器用電磁感應」✗——揚聲器是磁場對電流施力；麥克風（動圈式）才是電磁感應。
  • 「電鍋、吹風機必須用交流電」✗——它們靠電流熱效應，直流也能發熱；必須用交流的是變壓器、電磁爐、無線充電。

槳向後推水，水同時向前推槳（船），是作用力與反作用力（第三定律）。其他選項都是物體想維持原來的運動狀態：(A) 身體想繼續前進；(B) 碗盤想保持靜止；(C) 衣服停下時水想繼續運動；(E) 鎚柄停住、鎚頭繼續往下。

慣性題的關鍵字是「突然停、突然動，某個東西還想照原樣」。看到「推別人、自己反方向動」就是第三定律。
第 7 題3-2 F = ma
質量 2.0 kg 的木塊靜止於光滑水平面上，受 10 N 的水平定力作用。2.0 秒後木塊的速度為多少 m/s？
看答案與解析

答案：C

a = F/m = 10 / 2.0 = 5.0 m/s2；v = v0 + at = 0 + 5.0 × 2.0 = 10 m/s。

兩步驟：先用力算加速度，再用加速度算速度。選 (B) 的人是只算到加速度就停了。
第 8 題高頻考點3-2 作用力與反作用力
一本書靜置於水平桌面上。下列哪一對力是「作用力與反作用力」？
看答案與解析

答案：B

作用力與反作用力必須是「甲對乙」與「乙對甲」，作用在兩個不同物體上、性質相同。書壓桌（作用在桌）↔ 桌推書（作用在書），都是接觸的正向力。(A) 兩力都作用在書上，是一對平衡力；書的重量的反作用力是「書吸引地球的力」。

檢查法：把兩個力寫成「誰對誰」，如果剛好主詞受詞對調（書對桌、桌對書），就是作用與反作用。重力和正向力雖然等大反向，但都是作用在書上，只是剛好平衡。
第 9 題3-2 電梯視重

第 12 題3-3 萬有引力與 g
某人在地表的重量為 600 N。若他搭太空船到離地面高度等於一個地球半徑的位置，所受地球引力約為多少牛頓？
看答案與解析

答案：C

引力 ∝ 1/r2，r 從地心量。地表 r = R，離地 R 時 r = 2R，引力變 1/4：600 ÷ 4 = 150 N。

陷阱是以為「高度 = R」所以距離是 R。距離要從地球中心算，是 R + R = 2R，平方後是 4 倍，力剩 1/4。也不會是 0：太空中還是有重力。
第 13 題高頻考點4-1 右手定則
一條長直導線沿南北方向水平放在羅盤正上方，通電後電流由南向北流。羅盤磁針的 N 極會往哪個方向偏轉？（忽略地磁以外的干擾，只問偏轉方向）
看答案與解析

答案：B

右手拇指指向北（電流方向），四指環繞導線：在導線下方，四指方向由東指向西，所以磁針所在處的磁場向西，N 極向西偏。這就是厄斯特實驗。

實際比一下右手：拇指指前方（北），手指從上面繞過去、從下面繞回來，下方的手指是往左（西）。若羅盤放在導線上方，就會變成向東偏。
第 14 題4-1 磁力線
關於磁力線的性質，下列敘述何者錯誤？
看答案與解析

答案：C

任一點的磁場只有一個方向，若兩條磁力線相交，交點就會有兩個切線方向，矛盾，所以磁力線不會相交。其餘皆正確。

第 16 題高頻考點4-2 冷次定律
將條形磁鐵的 N 極朝向一個封閉的圓形線圈並向線圈靠近。從磁鐵這一側看線圈，線圈上應電流的方向，以及線圈與磁鐵之間的磁力為何？
看答案與解析

答案：D

N 極靠近 → 穿過線圈、指向遠離磁鐵方向的磁通量增加 → 應電流的磁場要反向，即指向磁鐵 → 線圈面對磁鐵的一面成為 N 極，與磁鐵 N 極互相排斥（來拒）。磁場朝向觀察者時，由右手定則，觀察者看到的電流為逆時針。

先決定「線圈對磁鐵那面要變什麼極」：靠近就排斥 → 變成同極 N。再用右手：拇指朝自己（N 極朝自己），四指就是逆時針。
第 17 題4-2 應電流產生條件
下列哪一種情況，封閉線圈中不會產生應電流？
看答案與解析

應電流的條件是磁通量發生變化。磁鐵靜止時，穿過線圈的磁力線再多也不會改變，所以沒有應電流。(D) 電流消失使磁場變化；(E) 轉動改變線圈面與磁場夾角，磁通量改變。

看答案與解析

第 23 題3-1 等加速度運動
一輛汽車以 72 km/h 等速行駛，駕駛看到前方障礙物，經過 0.50 秒的反應時間後才踩煞車，煞車後汽車以 5.0 m/s2 的加速度大小等減速至停止。
(1) 72 km/h 等於多少 m/s？
(2) 反應時間內汽車前進多少公尺？
(3) 從看到障礙物到停下，汽車共前進多少公尺？
看答案與解析

答案：(1) 20 m/s (2) 10 m (3) 50 m

(2) 反應時間內仍等速：20 × 0.50 = 10 m。
(3) 煞車距離：v2 = v02 + 2ax → 0 = 202 − 2 × 5.0 × x → x = 40 m。總共 10 + 40 = 50 m。

第 24 題3-2 F = ma（含摩擦力）
質量 4.0 kg 的木箱靜止在水平地面上，以 20 N 的水平力拉動它，木箱與地面間的動摩擦力為 8.0 N。
(1) 木箱的加速度為多少？
(2) 拉動 4.0 秒後木箱的速度為多少？
(3) 這 4.0 秒內木箱移動多遠？
看答案與解析

答案：(1) 3.0 m/s2 (2) 12 m/s (3) 24 m

(1) 合力 = 20 − 8.0 = 12 N，a = 12 / 4.0 = 3.0 m/s2。
(2) v = 0 + 3.0 × 4.0 = 12 m/s。
(3) x = ½ × 3.0 × 4.02 = 24 m（或平均速度 6 m/s × 4 s）。

(2) 放開拉力瞬間木箱的速度，以及拉動期間移動的距離？（3 分）
(3) 放開拉力後木箱還能滑行多遠、多久才停下？（3 分）
看答案、解析與評分標準

答案：(1) 4.0 m/s2 (2) 12 m/s；18 m (3) 再滑 36 m，歷時 6.0 s

(1) 合力 = 30 − 10 = 20 N，a = 20 / 5.0 = 4.0 m/s2。
(2) v = 4.0 × 3.0 = 12 m/s；x = ½ × 4.0 × 3.02 = 18 m。
(3) 放開後只剩摩擦力：減速度 = 10 / 5.0 = 2.0 m/s2。時間 = 12 / 2.0 = 6.0 s；距離 = 122 / (2 × 2.0) = 36 m（或平均速度 6 m/s × 6 s）。

評分標準：(1) 有扣摩擦力的合力 1 分、答案 1 分（用 30 ÷ 5 = 6 得 0 分）。(2) 速度 1 分、距離 2 分。(3) 減速度 1 分、距離 1 分、時間 1 分。

分兩段：第一段「拉力 − 摩擦力」在加速，第二段「只剩摩擦力」在減速。第二段的初速就是第一段的末速，這是兩段之間的橋。
25.4-2 冷次定律與能量改編自：松山高中 109-1 第二次段考 非選第 1 題8 分
如圖，ㄈ形光滑金屬軌道水平放置（左端封閉），一根金屬棒橫跨在軌道上，與軌道形成封閉迴路；整個裝置處在垂直射入紙面的均勻磁場中（圖中 ×）。施力使金屬棒獲得向右的速度 v 後立即放手。 (1) 金屬棒向右運動時，穿過迴路的磁通量增加還是減少？（2 分）
(2) 從紙面正前方看，迴路中應電流的方向為順時針還是逆時針？請說明判斷過程。（3 分）
(3) 放手後金屬棒會越來越快、等速運動，還是越來越慢？請用能量的觀點說明。（3 分）
看答案、解析與評分標準

答案：(1) 增加 (2) 逆時針 (3) 越來越慢

(1) 金屬棒右移，迴路面積變大，穿過的磁力線（射入紙面）變多，磁通量增加。
(2) 依冷次定律，應電流的磁場要反抗「射入紙面的磁通量增加」，所以應電流的磁場要射出紙面；右手拇指朝向自己（射出紙面），四指彎曲方向為逆時針。此時金屬棒中的電流由下往上。
(3) 越來越慢。迴路中的應電流會發熱（產生電能），這些能量只能來自金屬棒的動能，因此金屬棒的動能減少、速率變慢；從力的角度，載流的金屬棒在磁場中受到向左、阻礙運動的磁力。若應電流是順時針，金屬棒受力會向右、越跑越快，同時還不斷產生電能，等於無中生有，違反能量守恆。

評分標準：(1) 2 分。(2) 答案 1 分，寫出「反抗增加 → 應電流磁場射出紙面」1 分，右手定則 1 分。(3) 答「越來越慢」1 分，用能量守恆說明 2 分（只寫「冷次定律」未說明能量給 1 分）。

冷次定律不是死背的規則，它的背後就是「天下沒有白吃的午餐」：想要電，就得用動能來換，所以棒子一定會慢下來。方向判斷照四步走：原磁場方向 → 增或減 → 反抗 → 右手。

這次段考的計算與判斷題型很固定，下面 8 種方法練熟，就能應付大部分題目。每個方法先看例題，再自己做「換你試試」。

1. 等加速度運動：三公式怎麼挑

看到什麼就用

題目說「等加速度」「均勻加速／減速」「煞車」，給了 v0、v、a、t、x 其中三個，要求第四個。

例題：汽車以 10 m/s 行駛，以 2.0 m/s2 等加速 5.0 秒，求末速與這段時間的位移。

  1. 列出已知：v0 = 10 m/s、a = 2.0 m/s2、t = 5.0 s；求 v、x。
  2. 求 v（不需要 x）：v = v0 + at = 10 + 2.0 × 5.0 = 20 m/s。
  3. 求 x（不需要 v）：x = v0t + ½at2 = 50 + 25 = 75 m。
  4. 驗算：平均速度 (10 + 20)/2 = 15 m/s，15 × 5.0 = 75 m ✓。
換你試試等加速度
汽車以 30 m/s 行駛，緊急煞車時加速度大小為 6.0 m/s2。求煞車距離與煞車時間。
看答案

答案：75 m；5.0 s

沒給時間 → v2 = v02 + 2ax：0 = 302 − 2 × 6.0 × x → x = 900 / 12 = 75 m。時間：0 = 30 − 6.0t → t = 5.0 s。

減速時 a 代負號（或在公式裡寫成減號），不然會算出負的距離。

2. v-t 圖：斜率與面積

看到什麼就用

題目給一張速度－時間圖，問加速度、位移、平均速度、何時回頭。

例題：一物體 0～4 s 由靜止等加速到 8 m/s，4～10 s 等速，10～12 s 等減速到停止（即章節導覽 3-1 的圖）。求總位移與全程平均速度。

  1. 切段：0～4 s 三角形、4～10 s 長方形、10～12 s 三角形。
  2. 算面積：½ × 4 × 8 = 16；6 × 8 = 48；½ × 2 × 8 = 8。
  3. 相加：總位移 = 16 + 48 + 8 = 72 m。
  4. 平均速度 = 72 ÷ 12 = 6 m/s。（各段加速度：+2、0、−4 m/s2，看斜率。）
換你試試v-t 圖
一物體 0～5 s 由靜止等加速到 10 m/s，之後 5～8 s 維持 10 m/s 等速。求 (1) 前 5 秒的加速度 (2) 0～8 s 的位移 (3) 0～8 s 的平均速度。
看答案

答案：(1) 2.0 m/s2 (2) 55 m (3) 約 6.9 m/s

(1) 斜率 = 10 / 5 = 2.0 m/s2。(2) 面積 = ½ × 5 × 10 + 3 × 10 = 25 + 30 = 55 m。(3) 55 / 8 = 6.875 ≈ 6.9 m/s。

梯形或三角形的面積公式記熟，這類題目就是國中數學。

3. 自由落體與鉛直上拋

看到什麼就用

「由靜止落下」「鉛直上拋」「不計空氣阻力」→ a = g（向下），用等加速度公式。

例題：以 20 m/s 將球鉛直上拋，g = 10 m/s2。求到最高點的時間、最大高度、回到手中的總時間。

  1. 最高點速度 = 0：0 = 20 − 10t → t = 2.0 s。
  2. 最大高度：H = v02/2g = 400 / 20 = 20 m。
  3. 上下對稱：總時間 = 2 × 2.0 = 4.0 s，回到手中速率仍是 20 m/s（向下）。
換你試試自由落體
一顆石頭從 80 m 高的樓頂由靜止落下，g = 10 m/s2，不計空氣阻力。多久落地？落地速率多少？
看答案

答案：4.0 s；40 m/s

80 = ½ × 10 × t2 → t2 = 16 → t = 4.0 s；v = 10 × 4.0 = 40 m/s。

背「5、20、45、80」就能秒答：80 m 對應第 4 秒。

4. F = ma：受力分析

看到什麼就用

題目給力和質量（或給加速度反求力），常搭配摩擦力。

例題：2.0 kg 的木塊受 14 N 水平拉力，動摩擦力 4.0 N，求加速度。

  1. 畫力：拉力 14 N（向右）、摩擦力 4.0 N（向左）；鉛直方向重力與正向力抵消。
  2. 合力 = 14 − 4.0 = 10 N（向右）。
  3. a = F合/m = 10 / 2.0 = 5.0 m/s2（向右）。
換你試試F = ma
以 18 N 的水平力推一個 3.0 kg 的箱子，測得箱子的加速度為 4.0 m/s2。箱子所受的摩擦力是多少？
看答案

答案：6.0 N

合力 = ma = 3.0 × 4.0 = 12 N；摩擦力 = 18 − 12 = 6.0 N。

反求題：先算「需要多少合力才能這樣加速」，推力多出來的部分就是被摩擦力吃掉的。

5. 電梯視重

看到什麼就用

電梯、磅秤、「讀數」「感覺變重／變輕」。

例題：60 kg 的人站在以 2.0 m/s2 加速上升的電梯內磅秤上，g = 10 m/s2，讀數為多少？

  1. 判斷加速度方向：加速上升 → 加速度向上。
  2. 取向上為正：N − mg = ma。
  3. N = m(g + a) = 60 × 12 = 720 N = 72 kgw。
換你試試電梯
50 kg 的人站在以 3.0 m/s2 加速下降的電梯內磅秤上（g = 10 m/s2），讀數為多少 N？相當於多少 kgw？
看答案

答案：350 N；35 kgw

加速下降 → 加速度向下：N = m(g − a) = 50 × 7.0 = 350 N = 35 kgw。

電梯往下衝的那一刻，腳底輕飄飄，就是磅秤讀數變小了。

6. 克卜勒第三定律：比例計算

看到什麼就用

給軌道半徑求週期（或反過來），題目常以地球 1 AU、1 年為基準，或給一張行星數據表。

例題：火星平均軌道半徑約 1.5 AU，求公轉週期。

  1. 確認同一中心天體（都繞太陽）✓。
  2. 寫比例：(T/1 年)2 = (R/1 AU)3。
  3. 代入：T2 = 1.53 = 3.375 → T ≈ 1.84 ≈ 1.8 年。
  4. 直覺檢查：比地球遠 → 週期比 1 年長 ✓。
換你試試克卜勒第三定律
某顆彗星的平均軌道半徑為 16 AU，它的公轉週期是多少年？
看答案

答案：64 年

T2 = 163 = 4096 → T = 64 年。（或 T = 163/2 = 43 = 64。）

半徑是完全平方數時最好算：先開根號（16 → 4），再立方（4 → 64）。

7. 重力加速度的比例

看到什麼就用

「某行星質量為地球的 ○ 倍、半徑為 ○ 倍」「離地高度 ○」，問 g 或體重。

例題：某行星質量為地球的 2 倍、半徑為地球的 2 倍，其表面重力加速度為地球的幾倍？

  1. 寫出公式：g = GM/R2 → g ∝ M/R2。
  2. 代倍數：2 / 22 = 2/4 = 1/2。
  3. 答：地球的 1/2 倍。
換你試試g 的比例
某行星質量為地球的 9 倍、半徑為地球的 3 倍。一個在地球上重 600 N 的人，到這顆行星表面重多少牛頓？他的質量會改變嗎？
看答案

答案：600 N；質量不變

g ∝ 9/32 = 1，表面重力加速度與地球相同，所以體重仍為 600 N。質量是物體本身的性質，任何地方都一樣。

質量變大會讓 g 變大，半徑變大會讓 g 變小（而且是平方），兩個效果剛好抵消。

8. 冷次定律判斷應電流方向

看到什麼就用

磁鐵靠近／遠離線圈、線圈進出磁場、開關接通／斷開、金屬棒在軌道上滑動，問應電流方向或線圈與磁鐵間的力。

例題：條形磁鐵的 N 極對著圓形線圈，磁鐵遠離線圈。從磁鐵這一側看，應電流方向為何？線圈與磁鐵相吸還是相斥？

  1. 原磁場：N 極發出磁力線，在線圈處的方向是「離開磁鐵」（從觀察者這側穿過線圈往後）。
  2. 變化：磁鐵遠離 → 磁通量減少。
  3. 反抗：減少 → 應電流的磁場與原磁場同向，也是離開磁鐵（指離觀察者）。線圈面對磁鐵的一面是磁力線「進入」的面 → S 極。
  4. 右手：拇指指離觀察者，四指方向從觀察者看是順時針。S 極面對 N 極 → 相吸（去留）。
換你試試冷次定律
條形磁鐵的 S 極對著圓形線圈並靠近線圈。從磁鐵這一側看，應電流方向為何？線圈與磁鐵相吸還是相斥？
看答案

答案：順時針；相斥

S 極處磁力線進入磁鐵，所以線圈處的原磁場「指向磁鐵」（朝觀察者）；靠近 → 磁通量增加 → 應電流磁場反向，指離觀察者 → 從觀察者看為順時針。線圈面對磁鐵的一面成為 S 極，與磁鐵 S 極相斥（來拒）。

捷徑：先用「來拒去留」決定線圈那面的極性（靠近 → 同極相斥 → 面對 S 的那面也是 S），再用「四指電流、拇指 N 極」反推：N 極在背面，拇指朝後，從前面看就是順時針。

52–60 分鐘檢查答案卡：題號對齊、多選題有無漏塗、2B 鉛筆塗滿。下課鐘響畢就要停筆，不可提早交卷。
小撇步
  • km/h 一看到就先除以 3.6 換成 m/s。
  • 計算題先定「哪個方向為正」，反彈、減速、上拋時正負號最容易出錯。
  • 判斷應電流方向固定走四步：原磁場方向 → 增或減 → 增反減同 → 右手。
  • 題目出現「不」「錯誤」「何者不是」，先圈起來再作答。

常見失分原因

失分原因怎麼避免
平均速度與平均速率混用；往返平均速率直接把兩個速率平均速度看位移、速率看路徑；往返用「總路徑 ÷ 總時間」。
「第 n 秒內」與「n 秒內」搞混第 n 秒內只算一秒，用 1 : 3 : 5 : 7。
F = ma 忘了扣摩擦力F 一律寫成 F合，先畫力圖。
把重力與正向力當成作用力與反作用力檢查兩個力是不是作用在不同物體上。
以為合力方向就是運動方向合力決定加速度方向；煞車的車、上拋的球都是反例。
克卜勒第三定律平方、立方放反記「半徑立方、週期平方」：R3 ∝ T2，R = 4 → T = 8。
高度沒有加上地球半徑r 從地心量。
直導線與線圈的右手定則用反直導線「拇指電流」；線圈「四指電流」。
平行導線同向以為相斥電流「同向相吸」，跟電荷相反。
厄斯特、法拉第張冠李戴；電動機、發電機能量轉換相反「厄斯特電生磁、法拉第磁生電」；「電動機電→動、發電機動→電」。
以為穩定磁場或直流電也能感應出電流「磁生電，要變化」。
