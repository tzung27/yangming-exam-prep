一

知性題

必考給你一段文章（或圖表），先考你讀懂沒有，再要你提出自己的看法並舉例說明。
測驗目標
大考中心說明為「以測驗知性統整判斷能力為主」：統整材料重點、分析比較、判斷利弊、提出有根據的看法。
學測配分
25 分＝問題（一）4 分＋問題（二）21 分（112–115 學測皆如此）
字數
問題（一）約 80 字以內（至多 4 行）；問題（二）約 400 字以內（至多 19 行）
作答位置
學測：答題卷「正面」；段考依老師的答案卷規定
文體
說明文＋議論文（說理為主，可以有例子，不需要抒情）

題型樣式

一段約 500–900 字的引導材料（新聞、科普、書摘、電影情節、對話），接著兩個小題：

  • 問題（一）讀懂題：「依據上文，說明……有哪些特徵／差異／理由」。答案就在文章裡，考你會不會抓重點、換成自己的話、條列清楚。
  • 問題（二）論述題：「就你的觀察／生活見聞，舉例說明你的看法」。常見任務：分析正負影響、比較兩種態度並選邊、提出做法、表達看法與省思。

結構圖：一篇 400 字知性短文怎麼長

  1. 第 1 段 破題扣題關鍵詞＋表明立場（2–3 句，約 70 字）
  2. 第 2 段 論點一＋例理由→具體例子→回扣論點（約 130 字）
  3. 第 3 段 論點二／反面另一面、限制或對比（約 120 字）
  4. 第 4 段 結論收束立場＋提出做法或省思（約 70 字）

問題（一）不用分段，直接「①……；②……。」條列兩三點就好。

評分重點（依大考中心公布的閱卷評分原則整理）

小題等級／分數評分關鍵字
問題（一）
4 分		A 等：4 或 3 分確切說明、內容完整、表達清晰
B 等：2 分大致說明，但不夠完整或文字欠周延
C 等：1 分略涉題旨、解讀有誤、敘述混亂
問題（二）
21 分		A+：19–21事例適切、論點明確、詮釋深入（有思辨深度）、結構嚴謹、文辭暢達／洗練
A：15–18事例具體、觀點清楚、結構允當、條理分明、文辭流暢
B+：12–14能表述觀點、論述尚稱適當、結構合宜、文辭通順
B：8–11大致表述觀點，但論述平平
C+：5–7稍涉題旨、觀點不清、舉例不當、結構鬆散
C：1–4立論含糊、敘寫雜亂、文句不通

空白、文不對題、只抄題幹 0 分；字數不符、錯別字過多斟酌扣分。各年用詞略有不同，以大考中心當年公布為準。

常見題材

  • 科技與人（AI、社群、演算法）
  • 媒體與粉絲（擬社會互動）
  • 標籤與刻板印象
  • 生活態度與價值選擇
  • 倫理與責任（動物、他人）
  • 高齡社會、樂齡
  • 記憶與科技、虛擬幸福
  • 環境與永續
知性題最常考

① 問題（一）的「兩個重點都要寫到」：題目問差異就要寫兩邊、問正負面就兩面都寫，漏一邊直接掉到 B。② 問題（二）的「立場清楚＋例子具體」：只講大道理沒有例子，最多 B 級。

知性題四字訣：「抓、換、立、證」——抓材料重點、換成自己的話、立明確立場、證以具體事例。
二

情意題

常考給你一段引導文字（散文、詩、圖文）和一個題目，寫你自己的經驗、感受與體悟。
測驗目標
大考中心說明為「以測驗情意感受抒發能力為主」：觀察、感受、描寫、聯想、反思。
學測配分
25 分（不分小題）
字數
通常「文長不限」或不特別限制；實務上 600–800 字最穩（學測答題卷背面約可寫 30 多行）
作答位置
學測：答題卷「背面」
文體
記敘＋抒情散文（可加少量議論做收束）

題型樣式

  • 命題作文：直接給題目，例如「花草樹木的氣味記憶」「縫隙的聯想」「隔在我們之間的種種」。
  • 引導材料：一段名家散文、新詩、繪本圖文，告訴你「往哪個方向想」。
  • 寫作任務：題目最後一段通常會列出「要寫什麼」，例如：描述原因、你怎麼看待、換位思考、提出回應。這些就是你的段落清單。

結構圖：情意題的「物—事—情—悟」

第 1 段
起：畫面切入

用一個感官細節（氣味、聲音、光影）或一句對話開場，立刻扣題目的關鍵物。

第 2 段
承：具體經驗

一件事寫清楚：時間、地點、人物、動作、對話。細節越具體越真。

第 3 段
轉：心境轉折

當時沒懂、後來懂了；或從抗拒到接納。有「變化」文章才有深度。

第 4 段
深化：延伸聯想

從自己的事延伸到人與人、人與世界的關係（題目要求「換位思考」時就寫在這段）。

第 5 段
合：體悟收束

回到開頭的意象（首尾呼應），用一兩句有餘韻的話收尾。

評分重點（依大考中心公布的閱卷評分原則整理）

等級分數評分關鍵字
A+22–25扣題具體深刻、經驗與情境細膩動人、結構嚴謹、文辭洗練／優美、情感雋永
A18–21書寫清楚具體、結構完整、文辭暢達、情感深刻
B+14–17書寫適當但稍欠深刻、情感表達合宜、結構清楚、文辭通順
B10–13大致切題、內容較乏深刻或描寫籠統、結構尚可
C+6–9內容空洞或不切情理、結構欠佳、文辭浮泛
C1–5無法掌握題旨、敘寫雜亂、文句不通

另外視標點符號、錯別字多寡斟酌扣分。

常見題材

  • 感官記憶（氣味、聲音）
  • 人際關係（親子、朋友、隔閡）
  • 物件象徵（冰箱、課本、抽屜）
  • 自然意象（縫隙、樹、鯨魚）
  • 成長與自我認同
  • 學習經驗
  • 孤獨與被理解
情意題最常考

題目裡的「關鍵物」（氣味、縫隙、冰箱、52 赫茲）不能只當開場道具，要貫穿全文，最後還要從它得到體悟。只寫一個感人故事卻沒回扣關鍵物，就是「偏題」。

情意題口訣：「物起、事承、情轉、悟合」——物件開場、事件鋪陳、情感轉折、體悟收尾。

章節內容

  • 六級制：每題先判等級（A+、A、B+、B、C+、C），再在等級內給分。閱卷老師是「整體印象＋對照標準卷」，所以第一段就要讓人知道你懂題目。
  • 0 分情況：空白、文不對題、只抄題幹（題目材料照抄不算你的文字）。
  • 斟酌扣分：字數不符要求、錯別字過多、標點符號使用不當。
  • 作答區：學測規定第一大題寫正面、第二大題寫背面；寫錯區（例如從第二大題的作答區開始寫第一大題）扣 1 分。
  • 字跡：答卷會掃描後線上閱卷，字太小、太潦草可能影響成績。

圖解：閱卷老師的判斷順序

  1. 切題嗎？不切題直接落到 C 或 0
  2. 任務完成嗎？題目要求的每一項都有寫到
  3. 內容深嗎？例子具體、看法有層次
  4. 結構清楚嗎？分段合理、前後呼應
  5. 文字好嗎？通順→暢達→洗練
  6. 扣分項字數、錯字、標點、作答區

趨勢最值得注意

近三年知性題都牽涉「人和人／人和世界的關係」（標籤、粉絲、倫理責任）；情意題連續兩年寫「被理解／溝通」（52 赫茲、隔閡）。準備素材時，人際、科技、責任三類一定要有。

寫作技巧整理

依寫作順序排列：審題 → 立意 → 結構 → 段落 → 開頭結尾 → 修辭 → 引用 → 字數與時間。每一節都有「做法」和「範例」。

一、審題：先讀懂題目要你做什麼

核心觀念

國寫的題目最後一段就是「任務清單」。把每個動詞圈起來（說明、分析、比較、舉例、表達看法、描述、換位思考、提出回應），一個動詞＝你文章裡至少一段。

  1. 圈題目：題目名稱（如「縫隙的聯想」）裡的關鍵詞要原封不動出現在你的第一段。
  2. 劃任務動詞：「說明原因」「你怎樣看待」「換位思考」「提出回應」——四個動詞就是四段。
  3. 標限制條件：字數（80／400／不限）、範圍（「生活見聞」「成長過程」「任一學科」）、對象（親人、師長、同學、朋友）。
  4. 讀引導材料找方向：材料告訴你「出題者想要的角度」，但不能只重述材料，要寫你自己的。
題目常見動詞要你做的事易犯錯誤
依據上文說明從材料找答案，換句話說加入自己的意見（多寫不加分）
分析差異兩邊各寫一句，用「而」「相對地」連接只寫一邊
權衡利弊／正負影響利、弊都寫，最後表態只寫一面，或寫完不表態
舉例說明看法具體的人、事、時、地舉「有些人」「很多人」這種空泛例子
表達省思寫「我」的反省與改變只批評別人
描述／書寫感受畫面＋五感＋情緒變化用形容詞堆砌（很難過、很感動）
換位思考寫出「對方當時可能怎麼想」只寫自己委屈

二、立意：找一個比別人深一層的中心思想

立意＝整篇文章想說的那一句話。B 級文章的立意常是「大家都會說的話」，A 級文章多了一個轉折或條件。

題目普通立意（B）深一層立意（A／A+）
標籤不要隨便貼標籤標籤是方便的地圖，但地圖不是土地；能被撕下、能被改寫的標籤才有價值
縫隙人生需要休息縫隙不是缺口，是讓光進來、讓新的自己長出來的地方
擬社會互動追星有好有壞關鍵不在追不追，而在能否分清「被陪伴的感覺」與「真實的關係」
隔閡要多溝通隔閡常是「太在乎」造成的；先說出在乎，牆就變成窗
小撇步：立意升級三招
  • 加條件：「……，但前提是……」
  • 翻轉：「表面上是……，其實是……」
  • 由己及人：「我以為只有我……，後來發現每個人都……」

三、結構：先決定段數，再寫

知性短文（約 400 字）

四段：破題立場 → 論點一＋例 → 論點二／反面＋例 → 結論與做法。每段 3–5 句。問題（一）不分段。

情意文章（600–800 字）

四到五段：畫面開場 → 經驗 → 轉折 → 延伸 → 體悟收尾。中間段可以比較長，頭尾短而有力。

易錯陷阱

一段到底（整篇不分段）、或十幾個一兩句的小段，都會被判「結構鬆散」。知性 400 字就 4 段，情意 700 字就 5 段，最安全。

四、段落：每段都有「主題句」

段落的第一句先講這段要說什麼（主題句），後面再展開。閱卷老師讀得快，第一句最重要。

段落類型寫法例
論證段論點 → 解釋 → 例子 → 回扣（PEEL：Point、Explain、Example、Link）「標籤也能成為前進的燈。被肯定的稱呼會改變人對自己的期待，像班上被叫『小老師』的同學，從此每次都先把題目弄懂再去教人。可見好的標籤是一種邀請。」
記敘段時間地點 → 動作 → 細節（五感） → 當下心情「那天傍晚，外婆把曬乾的桂花倒進玻璃罐，甜香一下子漫過整個廚房，我卻只顧著滑手機。」
抒情段情緒 → 原因 → 意象化「後來我才懂，那罐桂花是她說不出口的『想你』。」

段與段之間要有銜接：然而、相對地、更重要的是、回頭看、直到那天、如今。

五、開頭與結尾

開頭五法

  • 扣題直述（知性最穩）：「當公眾人物在螢幕那端微笑時，許多人以為自己被看見了。」
  • 畫面切入（情意最好用）：「雨停後，陽台的茉莉在夜裡悄悄放出香氣。」
  • 對話開場：「『你到底在想什麼？』這句話，我聽了好多年。」
  • 設問：「如果記憶可以刪除，你會刪掉哪一段？」
  • 引用：「孔子說：『己所不欲，勿施於人。』……」（引完一定要接自己的話）

結尾四法

  • 首尾呼應：回到開頭的意象（茉莉、雨、那句話）。
  • 提出行動（知性）：「與其禁止，不如……」
  • 昇華體悟（情意）：從一件小事看見一個道理。
  • 留白餘韻：用一個畫面收尾，不把話說滿。
不要這樣開頭

「隨著時代的進步，科技越來越發達……」「在這個資訊爆炸的時代……」——太多人用，閱卷老師一眼就覺得普通。結尾也別寫「總而言之，我們要好好珍惜」這種口號。

六、修辭：少而準，放在關鍵處

修辭最適合放哪例
譬喻立意句、結尾標籤像一張便利貼，方便，卻也容易遮住底下的字。
排比論點總結它讓孤單的人有陪伴，讓迷惘的人有方向，也讓盲從的人失去判斷。
映襯轉折處螢幕裡的他無比靠近，現實中的他從不知道我的名字。
摹寫（五感）情意題經驗段鐵捲門嘎啦拉下，油鍋的劈啪聲也跟著停了。
轉化情意題意象那棵老樟樹守著校門，替每屆學生記住離開的背影。
設問／激問開頭、轉折我們真的認識那個每天在螢幕上道早安的人嗎？
層遞深化段從看見，到理解，再到願意靠近。
小撇步

一篇文章有 2–3 個漂亮的句子就夠了，放在第一段、轉折段、最後一段，閱卷老師最容易看到。整篇都在修辭反而顯得空。

七、引用：名言、例子、數據

  • 引用不是越多越好：一篇 400 字的知性短文，最多一句名言＋一個例子。
  • 引用要「解釋＋連結」：引完要用自己的話說「這句話放到本題，代表……」。
  • 不確定的不要寫：作者、年份、數字記不清楚，就改寫成「有人說」或用自己的經驗，不要硬掰。錯誤引用比不引用更傷印象分。
  • 生活例子最安全：自己的、同學的、家人的經驗，具體又不會錯；名人例子當作加分。

可用的公版名言與例子，請看「結構公式與素材庫」分頁的素材分類表。

結構公式與素材庫

像數學公式一樣：先記結構，考場上把題目代進去。後半是素材庫，人物、事件、名言、時事分類整理，每類挑 2–3 個熟到可以寫的就夠。

1. 知性題結構公式

知性（一）短答公式（80 字）
依據上文，① 重點一（換句話說）；② 重點二；（③ 重點三）。
題目問「差異」：「甲……，而乙……；因此甲重在……，乙重在……。」問「正負面」：「正面：……；負面：……。」不寫開場白、不加自己的意見。
知性（二）「表態型」公式（400 字）
立場 ＋ 理由一（例） ＋ 理由二（例） ＋ 回應反方 ＋ 結論做法
適用：你支持嗎？你傾向哪一種？（110 經驗機器、112 福爾摩斯與華生）
知性（二）「利弊型」公式
現象定義 ＋ 正面影響（例） ＋ 負面影響（例） ＋ 關鍵在於……（自己的判準）
適用：闡述正、負面影響（114 擬社會互動）、標籤的看法（113）。最後一段一定要提出「判準」，不能只是「有好有壞」。
知性（二）「事例省思型」公式
扣題概念 ＋ 事例（人事時地＋選擇） ＋ 分析（為什麼這樣選） ＋ 省思（我會怎麼做）
適用：舉出生活見聞中……的事例，表達看法與省思（115「臉」的召喚）。例子一個就好，寫深寫透。
知性（二）「意義＋做法型」公式
意義（為什麼值得做） ＋ 做法一（對應需求一） ＋ 做法二（對應需求二） ＋ 結語
適用：說明……的意義，並思考如何……（111 樂齡出遊：生理需求、情感需求分兩段寫）。

2. 情意題結構公式

「物—事—情—悟」公式
物（感官畫面） → 事（一件具體經驗） → 情（當下與後來的變化） → 悟（從物得到的體會）
適用：氣味記憶、新冰箱、課本、52 赫茲這類「以物為題」。物要貫穿全文。
「今—昔—今」倒敘公式
現在的畫面 → 回想過去的事 → 回到現在，有了新的理解
適用：記憶、成長、人際題。首尾在同一個場景，最容易做出「首尾呼應」。
「自然 → 人生」聯想公式
自然現象的特性 → 我生命中相似的情境 → 我的轉變 → 人生道理
適用：縫隙的聯想、樹、海、季節。第一段先說清楚「自然現象為什麼這樣」（題目常要求），再進入人生。
「關係 → 換位 → 回應」公式
隔閡／衝突的事件 → 原因（我的視角） → 換位（對方的視角） → 我的回應與改變
適用：115 隔在我們之間的種種、親子、友情題。換位那段要寫得具體：「他那時大概是……」。
知性四型：「表態、利弊、事例、做法」；情意四型：「物事情悟、今昔今、自然到人生、關係換位」。

3. 萬用句型

用途句型用法提醒
破題立場「……看似……，實則……。我認為……。」第一段第二句就表態
破題立場「與其說……，不如說……。」翻轉常見看法

這一頁怎麼來的

以下 12 題是大考中心 110–115 學年度學測「國語文寫作能力測驗」的真實題目（每年知性、情意各一題）。為了尊重著作權，題目只摘要主旨與寫作任務，沒有照抄引導材料；完整原題請到「模擬寫作測驗」分頁的來源表點連結下載。解析中的「評分重點」依大考中心公布的閱卷評分原則整理，「高分寫法」「常見失分」是依評分原則歸納的建議，不是官方範文。

用法：先只看題目，花 5 分鐘自己寫審題筆記（任務動詞、立場、例子、段落），再打開解析對照。

一、知性題

第 1 題115 學測知性・事例省思型
主旨：材料以韓劇中女主角不忍吃「對視過」的小豬、改吃魚的情節開場，引哲學家列維納斯對「臉」的說法：他人的「臉」所顯露的脆弱，會召喚我們做出關懷與承擔責任的回應；而「無臉」則可能成為逃避責任的托詞。
（一）依據上文，說明女主角為何拒吃小豬卻能接受吃魚。（80 字以內，4 分）
（二）就上文對「臉」的說明，舉出生活見聞中「選擇逃避」或「積極承擔」的事例，就如何做出選擇，表達看法與省思。（400 字以內，21 分）

審題拆解

（一）答案在材料裡：①和小豬多次對視，「眼神／臉」喚起她的共感，不忍吃；②魚「沒有臉」、不會與人對視，較難引發同情，所以能接受。
（二）任務動詞：「舉出事例」＋「就如何做出選擇」＋「看法與省思」。關鍵概念是「臉＝召喚責任的面貌」，不只是長相。

評分重點：大考中心評分原則中，A+ 要求事例恰當、看法與省思清楚、結構嚴謹且具說服力；舉例不當或未舉例落到 C+ 以下。

高分寫法：選一個具體場景（例如雨中在路口兜售的長者、被排擠的同學、班上沒人接的公共工作），寫出「我看見了他的臉 → 我當時想逃避的理由 → 我怎麼選 → 為什麼」；最後提出判準，例如「承擔不一定是英雄行為，而是不轉開視線」。

常見失分：①把「臉」只寫成外表、面子；②只寫動物保護、忘了題目也包括「他人」；③事例空泛（「社會上很多人冷漠」）；④只批評別人逃避，沒有「我」的省思。

這題其實在問：當你看見別人需要幫忙時，你是轉頭，還是停下來？先講一件你真的遇過的事，誠實寫出你想逃避的那一秒，再寫你最後的選擇。誠實比偉大更能打動閱卷老師。

審題拆解

一、知性題（共 25 分）
一知性利弊＋做法型自編（比照學測國寫知性題）25 分

閱讀下文，回答問題。

　　晚上十點，小晴本來只想看一支三分鐘的貓咪影片。影片結束，下一支自動播放，又是貓，接著是寵物醫生的衛教、領養活動、某位網紅的開箱。等她抬頭，已經過了一個小時。隔天和同學聊起最近的新聞，她才發現，大家說的事她一件也沒看過；而她以為「全世界都在討論」的話題，同學根本沒聽說。

　　這正是推薦演算法的運作方式。影音與社群平臺記錄使用者的點擊、停留秒數、按讚與分享，推算「你可能會喜歡什麼」，再把相似的內容排在最前面。平臺的目標是讓使用者停留得更久，因為停留時間越長，廣告收入越高。對使用者來說，這省去了搜尋的力氣，也常帶來驚喜：有人因此找到冷門的樂團、學會一道料理、認識志同道合的社群。

　　但長期下來，使用者看到的世界會越來越像自己。網路行動者伊萊・帕理澤（Eli Pariser）在 2011 年提出「過濾氣泡」的說法，提醒人們：當系統只餵給我們喜歡的、同意的資訊，不同的聲音便悄悄消失，我們還以為那就是世界的全貌。中文常用「同溫層」形容這種處境——身在其中的人覺得溫暖舒適，卻不容易察覺外頭的天氣已經改變。

　　有些平臺開始提供「不感興趣」「重設推薦」或依時間排序的選項；也有老師在課堂上請學生交換手機，看看彼此的首頁有多麼不同。演算法不會消失，問題或許在於：我們要讓它替我們決定看見什麼，還是由自己決定？

問題（一）：依據上文，說明「同溫層」是如何形成的。文長限 80 字以內。（占 4 分）
問題（二）：就你使用影音或社群平臺的經驗，寫一篇短文，說明推薦演算法對你帶來的正、負面影響，並提出你打算如何與它相處。文長限 400 字以內。（占 21 分）

看參考答案、評分規準與示範

問題（一）參考答案

平臺記錄使用者的點擊、停留與互動，推算喜好後優先推送相似內容；長期只接收自己喜歡、認同的資訊，不同聲音逐漸消失，使用者卻誤以為那就是世界全貌。（約 70 字）

給分要點：①機制（記錄行為→推送相似內容）②結果（資訊同質、異見消失）③錯覺（以為是全貌）。三點齊全、文字清楚 4 分；只寫到兩點 3 分；只寫一點或文字混亂 2 分；誤解為「人們自己只交同類朋友」等與材料不符者 1 分。

A 級寫作要點

  • 第一段就表明立場：演算法是「好用的嚮導」，但不能讓它當「唯一的地圖」。
  • 正面、負面各一個自己的例子，例子要有平臺、內容、時間、結果。
  • 點出「平臺的目的（讓你停留）」和「你的目的（學習、放鬆）」可能不一致，這是深度來源。
  • 做法要具體：主動搜尋、追蹤立場不同的來源、使用「不感興趣」、關閉自動播放、設定時間。

示範大綱（利弊＋做法型）

第 1 段
破題立場

演算法像一位很懂我的嚮導，但嚮導有自己的目的；我想讓它帶路，而不是替我決定去哪。

第 2 段
正面＋例

推薦讓我找到一個講解數學的頻道，段考前把不懂的觀念補起來——它省去搜尋，也帶來我原本不知道的好東西。

第 3 段
負面＋例

某次班上討論公共議題，我發現自己只看過支持一方的短影音；我以為的「大家都這樣想」，其實是演算法替我挑的。

第 4 段
判準＋做法

關鍵在主導權：關閉自動播放、每週主動搜尋一個不熟悉的主題、刻意追蹤立場不同的媒體；讓演算法成為工具，而不是習慣。

示範段落（第 3 段，約 120 字）

　　然而，嚮導帶的路，未必是我該走的路。上個月班會討論是否延長午休時間，我滔滔不絕地舉出好幾支影片的說法，卻被同學一句「另一邊的理由你看過嗎」問倒。回頭翻找才發現，我的首頁清一色是同一種聲音。演算法沒有騙我，它只是太「體貼」，體貼到替我擋掉了所有不同意見，而我竟把這片溫暖的同溫層，誤認成整個天空。

這段的得分點：①第一句是主題句（嚮導帶的路未必該走），延續第 1 段的比喻；②例子有時間、場合、對話，很具體；③最後一句回扣「同溫層」並用譬喻收尾。寫知性題不是不能有文采，而是文采要放在「說清楚道理」之後。
二、情意題（共 25 分）
二情意感官記憶型自編（比照學測國寫情意題）25 分

閱讀下文，回答問題。

　　搬家那天，最後離開空蕩蕩的舊屋時，我忽然聽見樓下傳來熟悉的聲音：鐵捲門被拉起時一陣長長的嘩啦，接著是早餐店老闆把鍋鏟敲在鐵板上的兩聲脆響。十年來，那是我每天醒來前聽見的第一個聲音，我從沒特別在意；直到要離開了，才發現它早已住進我的耳朵裡。

　　後來在新家，我常在清晨醒來，等著那陣嘩啦與那兩聲脆響，四周卻只有冷氣低低的運轉聲。原來有些聲音，平常像空氣一樣不被注意，卻悄悄替我們記住了一段日子、一群人，以及當時的自己。

請回答下列問題：生活中有許多聲音：雨打在鐵皮屋頂上、家人喚你的名字、教室裡翻書的沙沙聲、某首總在某個季節響起的歌……。請以「我收藏的一種聲音」為題，寫一篇文章，描寫一種你熟悉的聲音，說明它連結了哪些人、事或時光，並寫出你從中得到的感受與體悟。文長不限。（占 25 分）

審題拆解

三個任務：①描寫一種聲音（聽覺摹寫要具體）②它連結的人、事、時光（具體經驗）③感受與體悟。題目的「收藏」暗示：這聲音對你珍貴、你想留住它——結尾要寫出「為什麼收藏」。

示範段落（第 3 段，約 150 字）

　　升上高中那年，媽媽換了工作，常常加班到深夜。我推開家門，迎接我的不再是熱騰騰的蒸氣，而是一片沉默，只有冰箱在角落低低地嗡嗡作響，像一個不知道該說什麼的人。我打開電鍋，裡面空空的，內鍋冷得像一塊鐵。那一刻我才發現，原來這些年我嫌煩的那一聲「喀」，一直在替媽媽說：「你回來了，先吃點東西。」而我從來沒有回答過。

  4. 編號寫出：「①……；②……。」數字數，60–80 字。

材料大意：「甲社區把公園的草皮改成可以自己種菜的共享菜園，居民輪流照顧，收成一起分享；乙社區在公園裝了監視器和『禁止踐踏草皮』的告示，維護成本降低，但很少人來。」題目：「依據上文，說明兩社區管理公園的作法有何差異？（80 字以內）」下列哪一個答案最能得到 A 等？
看答案與解析

答案：C

(A) 加入自己的喜好，沒有說明差異。(B) 只寫甲、且照抄材料。(D) 只寫乙。(C) 兩邊都寫，並歸納出「參與 vs. 管制」的核心差異與結果。

問「差異」就一定要兩邊都寫，而且最好找出一組對比詞（參與／管制）。這就是 4 分和 2 分的差別。

2. 知性（二）：三分鐘定立場

  1. 寫出題目的核心問題：用一句問句寫在草稿紙上，例如「演算法推薦對我好不好？我怎麼用它？」
  2. 選立場：支持／反對／有條件支持。選你例子最多的那一邊，不是看起來最正確的那一邊。
  3. 寫一句立意句：用「關鍵不在……而在……」或譬喻，例如「演算法是好嚮導，卻不該是唯一的地圖。」
  4. 配兩個理由各一個例子：寫成關鍵詞就好。
換你試試立意
題目：「有人主張高中生上課時間應統一收手機。請就你的經驗表達看法。」下列哪一句作為立意句，最能展現思辨深度？
看答案與解析

答案：B

(A) 兩面討好、沒有立場。(C) 有立場，但理由單一且偏情緒，缺少教育角度的思考。(D) 是萬用開頭，沒有立場。(B) 區分「手段」與「目的」，提出判準（自律能力），立場清楚又有深度。

高分立意通常會「把問題往下挖一層」：大家在吵收不收，你去問「我們真正想要的是什麼」。

3. 情意題：找到「只屬於你」的素材

  1. 圈出關鍵物：題目中的「氣味」「縫隙」「聲音」「冰箱」。
  2. 聯想清單 1 分鐘：寫下 5 個你想到的具體東西（不是抽象詞）。
  3. 挑「有人、有事、有變化」的那一個：能連到一個人和一件事，而且你對它的感覺前後不一樣。
  4. 寫下轉折句：「以前我覺得……，直到……，才明白……。」這句就是全文的骨架。
換你試試情意素材
題目：「那一扇窗」。請用上面四步，寫出：（1）五個聯想；（2）你選的那一個與原因；（3）一句轉折句。
看參考示範

參考示範

（1）教室最後一排的窗、外婆家的木窗、公車車窗、醫院病房的窗、手機螢幕（另一種窗）。
（2）選「醫院病房的窗」：連到住院的阿公（人）、每天陪他看窗外工地蓋大樓（事）、從無聊到珍惜（變化）。
（3）「以前我覺得那扇窗外只有吵鬧的工地，直到阿公說他想看大樓蓋好，我才明白，窗外是他對明天的盼望。」

先別急著寫，一分鐘聯想能讓你避開「大家都會寫的那一扇窗」。挑那個讓你心裡一動的，就對了。

4. 十分鐘列大綱

  1. 套公式：知性用「表態／利弊／事例／做法」四型之一；情意用「物事情悟／今昔今／自然到人生／關係換位」之一。
  2. 每段寫一行：段旨＋關鍵詞（例子、修辭句）。
  3. 對照任務清單：題目的每個動詞都對應到某一段了嗎？
  4. 分配字數：知性 70／130／120／70；情意 100／200／180／150／80。
換你試試大綱
為 115 學測情意題「隔在我們之間的種種」列一份五段大綱（對象自選）。檢查是否包含題目要求的四個任務：原因、看法、換位思考、回應。
看參考示範

參考大綱（對象：爸爸）

①開頭：晚餐桌上只剩電視的聲音，爸爸問「考得怎樣」，我回「就那樣」。
②原因：他只問成績，我覺得他不在乎我；我用沉默回應，牆越來越高。（原因）
③看法：隔閡不是不愛，而是我們都用錯的方式表達在乎。（看法）
④換位：他小時候家裡窮，成績是他唯一的出路；問成績，是他知道的唯一關心方式。（換位思考）
⑤回應＋呼應：我先開口跟他說今天球賽的事，他愣了一下，然後笑了——電視聲變小了。（回應）

四個任務各佔一段，再加一個畫面開頭，大綱就完成了。考場上大綱寫成這樣就夠，不用寫完整句子。

5. 讓文章「深一層」：寫出轉折

  1. 找出你一開始的想法（通常是表面的、負面的）。
  2. 放一個觸發事件：一句話、一個畫面、一次失去。
  3. 寫出新的理解：用「原來」「我才明白」帶出。
  4. 把理解放大一點點：從「我和他」到「人與人」，但不要變成說教。
換你試試體悟句
情意題「縫隙的聯想」，前文寫自己因受傷退出球隊、在家休養兩個月，期間開始學畫畫。下列結尾句何者最能扣題又有餘韻？
看答案與解析

答案：D

(A) 偏離「縫隙」，變成安全宣導。(B) 口號式、沒有扣題。(C) 變成推薦文。(D) 回扣森林縫隙的意象（首尾呼應），把受傷的空白轉化為成長，有意象也有體悟。

結尾最好「回到題目的那個東西」。題目是縫隙，就讓縫隙在最後一句再出現一次，而且意思變得更深。

6. 最後五分鐘檢查

  1. 題號與作答區：第一大題、第二大題有沒有寫在對的位置、標對題號。
  2. 字數：知性（一）≤80 字、（二）≤400 字（數行數）。
  3. 錯別字：特別檢查「的／得」「在／再」「已／以」「做／作」「應該／因該」。
  4. 標點：一段不要只有一個句號；引號、書名號（《》〈〉）用對。
  5. 首尾：第一段有扣題關鍵詞、最後一段有回扣。
換你試試挑錯
找出下列句子的錯別字與標點問題，並改正：「我因該早點發現，他說的那些話其實是在關心我，只是我們都不知到怎麼說出口所以那道牆越來越高」
看答案與解析

參考答案

錯字：「因該」→「應該」；「不知到」→「不知道」。標點：「……怎麼說出口，所以那道牆越來越高。」（「出口」後加逗號，句末加句號）

「應該」「知道」這種常用字最容易寫錯，因為寫太快。檢查時用手指一個字一個字點過去，比用眼睛掃更有效。

考場提醒

作文要用黑色原子筆（文具不能跟別人借），可帶修正帶。考試不能提早交卷，鐘響完就停筆——所以寧可結尾短一點，也一定要寫完；沒有結尾的文章結構分會被扣很多。

常見失分原因

  • 偏題：題目要「花草樹木的氣味」，寫成食物；題目要「看法與省思」，只寫故事。
  • 任務沒做完：題目四個動詞只做了兩個（最常漏「換位思考」「提出做法」「表態」）。
  • 知性（一）超字數或照抄材料。
  • 例子空泛：「很多人」「有些人」「現在社會」。
  • 結構：不分段、或段落太碎；結尾沒寫完。
  • 陳腔濫調：「隨著科技的進步」開頭、「總而言之我們要珍惜」結尾。
  • 錯別字與標點：一逗到底、應該／因該、在／再。
  • 字太潦草或太小：閱卷老師看不懂就沒辦法給分。
