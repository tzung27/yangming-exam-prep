常用對數

必考第二章 指數、對數：把「乘法」變「加法」、把「很大的數」變成「好比較的小數」。
課本主題
常用對數的定義 log a＝x ⇔ 10x＝a；對數律；常用對數表（查表、內插，以課本為準）；科學記號與位數；應用（地震規模、分貝、pH、複利）
前置知識
2-1 指數律、科學記號
常考題型
log 化簡求值、an 是幾位數、首位數字、小數點後第幾位開始不為 0、比較大小、成長衰減「至少幾年」
考試提供
段考不能用計算機，題目通常會給 log2≈0.3010、log3≈0.4771、log7≈0.8451（log5＝1−log2≈0.6990）

章節內容

  • 定義：對正數 a，log a 是「10 要幾次方才會等於 a」。所以 log 1＝0、log 10＝1、log 100＝2、log 0.01＝−2。真數一定要是正數。
  • 對數律：乘變加、除變減、次方往前拿：log(ab)＝log a＋log b、log(a/b)＝log a−log b、log ar＝r log a。
  • 位數：寫成 N＝a×10n（1 ≤ a < 10）時，log N＝n＋log a，整數部分 n 決定大小（位數），小數部分 log a（0 ≤ log a < 1）決定首位數字。
  • 應用：地震規模、聲音分貝、酸鹼值、複利與人口成長、放射性衰變。

  2. 拆整數＋小數15.05＝15＋0.05
  3. 整數→位數1015 等級 ⇒ 16 位
  4. 小數→首位0 ≤ 0.05 < log2 ⇒ 首位 1

3-1

多項式的運算與應用

必考第三章 多項式函數：學會「多項式的除法」，再用餘式定理、因式定理快速算餘式、找因式。
課本主題
多項式的名詞（次數、係數、首項、常數項）、加減乘、除法原理、綜合除法、餘式定理、因式定理、插值多項式（已知幾個函數值求多項式）
前置知識
國中的多項式乘除、因式分解、乘法公式
常考題型
求 f(x) 除以一次式／二次式的餘式、因式定理求係數、連續綜合除法改寫成 (x−a) 的多項式、已知函數值求 f(x)

章節內容

  • 除法原理：f(x)＝g(x)·Q(x)＋r(x)，其中 r(x)＝0 或 deg r < deg g。除式是一次 ⇒ 餘式是常數；除式是二次 ⇒ 餘式設 ax＋b。
  • 綜合除法：除以 x−a 時，只寫係數（缺項補 0），「下拉、乘 a、相加」。除以 ax−b 時先用 x−ba 除，商再除以 a，餘式不變。
  • 餘式定理：f(x) 除以 x−a 的餘式＝f(a)；除以 ax−b 的餘式＝f(ba)。
  • 因式定理：x−a 是 f(x) 的因式 ⇔ f(a)＝0。
  • 連續綜合除法：把 f(x) 改寫成 a(x−h)3＋b(x−h)2＋c(x−h)＋d，用來求除以 (x−h)2 的餘式、近似值、對稱中心。
  • 插值多項式：已知 n＋1 個點，可以決定一個次數不超過 n 的多項式；已知根就先寫成因式乘積再代點（拉格朗日／牛頓插值的寫法以課本為準）。

圖解：綜合除法（2x3−5x2＋4x−7 除以 x−2）

x3x2x常數說明
係數2−54−7缺項要補 0
×2 往右上加4−24下面的數 ×2 寫到下一格
結果2−12−3商 2x2−x＋2，餘 −3
  1. 看除式次數一次 → 餘式是常數；二次 → 設 ax＋b
  2. 找讓除式＝0 的 x代進 f(x)＝Q·g＋r
  3. 商那項消失只剩 r 的方程式
  4. 解聯立得到餘式

這章最常考

① 除以二次式的餘式（設 ax＋b、代兩個根）；② 因式定理求未知係數；③ 除以 ax＋b（例如除以 2026x＋2026 其實就是代 x＝−1）；④ 已知三次函數的根與函數值，求 f(0) 或其他值。

簡單多項式函數及其圖形

必考認識函數，畫出一次函數（直線）與二次函數（拋物線），會配方找頂點與最大最小值。
課本主題
函數的意義（一個 x 對應唯一 y）、常數函數、一次函數（斜率）、二次函數圖形（開口、頂點、對稱軸）、圖形平移、最大值與最小值
前置知識
國中的一次函數、二次函數、配方法
常考題型
配方求頂點、限制範圍的最大最小值、由圖形判斷 a、b、c、判別式的正負、圖形平移後的方程式

章節內容

  • 一次函數 f(x)＝ax＋b：圖形是直線，a 是斜率，「x 每增加 1，y 增加 a」；兩點就能決定。
  • 二次函數 y＝ax2＋bx＋c（a≠0）配方成 y＝a(x−h)2＋k：頂點 (h, k)，h＝−b2a，對稱軸 x＝h。
  • 平移：y＝ax2 向右 h、向上 k ⇒ y＝a(x−h)2＋k（右移是「減」）。開口大小只看 |a|，平移不會改變 a。
  • 最值：全體實數時只看頂點；有範圍時比較「頂點（若在範圍內）」和「兩個端點」。
  • 與 x 軸交點：判別式 D＝b2−4ac：D>0 兩交點、D＝0 相切、D<0 不相交。

圖解：拋物線 y＝(x−2)2−1

看什麼判斷

對稱軸 x＝−b/(2a) 在 y 軸左或右在右邊 ⇒ a、b 異號；在左邊 ⇒ 同號（「左同右異」）

3-3

多項式函數的圖形（不含不等式）

常考三次函數的圖形一定有「對稱中心」，靠近中心像一條直線、離很遠像 y＝ax3。
課本主題
y＝ax3 與 y＝ax3＋px 的圖形、三次函數配成 y＝a(x−h)3＋p(x−h)＋k、對稱中心、局部的一次近似、廣域（大範圍）特徵
不考
本節後半的二次不等式、高次不等式
常考題型
求對稱中心、在某點附近的近似直線與近似值、由圖選函數、判斷能否由 y＝ax3 平移得到

章節內容

  • y＝ax3：對稱於原點；a>0 左下到右上，a<0 左上到右下。
  • y＝ax3＋px：仍對稱於原點；ap ≥ 0 時一路單調（沒有「起伏」），ap<0 時有一上一下的「波浪」，和 x 軸交三點。
  • 一般三次函數 y＝ax3＋bx2＋cx＋d：用連續綜合除法以 h＝−b3a 展開成 a(x−h)3＋p(x−h)＋k（平方項係數一定是 0），對稱中心 (h, k)＝(h, f(h))。
  • 一次近似：把 f(x) 寫成 (x−a) 的多項式後，x 很接近 a 時高次項很小，f(x) ≈ c(x−a)＋d，這條直線就是圖形在 x＝a 附近的樣子（在對稱中心附近就是 y＝p(x−h)＋k）。
  • 廣域特徵：|x| 很大時，f(x) 的走勢由首項 axn 決定。

圖解：y＝(x−1)3−3(x−1)＋1 的對稱中心

2-2 常用對數

一、定義

核心觀念

若 a > 0，滿足 10x＝a 的實數 x 只有一個，記作 x＝log a，叫做 a 的常用對數（以 10 為底），a 叫「真數」。

所以 10log a＝a、log 10x＝x。例：log 1000＝3、log 0.001＝−3、log √10＝12、log 1＝0。

易錯陷阱

log 0、log(−5) 沒有定義（10 的任何次方都是正數）。但 log a 本身可以是負數或 0，例如 log 0.5 < 0。

二、對數律（a、b > 0，r 為實數）

性質式子例子
乘變加log(ab)＝log a＋log blog 6＝log 2＋log 3 ≈ 0.7781
除變減log ab＝log a−log blog 5＝log 102＝1−log 2 ≈ 0.6990
次方往前log ar＝r log alog 8＝3 log 2 ≈ 0.9030
倒數log 1a＝−log alog 0.5＝−log 2 ≈ −0.3010
根號log √a＝12 log alog √3 ≈ 0.23855
常見錯誤
  • log(a＋b) ≠ log a＋log b（例如 log(1＋1)＝log 2 ≠ 0）。
  • (log a)2 ≠ log a2＝2 log a。
  • log alog b ≠ log ab。

三、單調性與比較大小

真數越大，log 越大：0 < a < b ⇔ log a < log b。所以比較 230、320、513：分別取 log 得 9.030、9.542、9.087，得 320 > 513 > 230。

反過來，比較 (0.1)log 3 與 (0.1)log 2：(0.1)log 3＝10−log 3＝13，(0.1)log 2＝12，所以前者較小。

四、科學記號、位數、首位數字

核心觀念

正數 N＝a×10n（1 ≤ a < 10，n 為整數）⇒ log N＝n＋log a，且 0 ≤ log a < 1。

  • 整數部分 n ≥ 0：N 的整數部分是 n＋1 位數。
  • n < 0（N < 1）：N 在小數點後第 |n| 位開始出現不為 0 的數字。
  • 小數部分 log a：找 k 使 log k ≤ log a < log(k＋1)，首位數字就是 k。
例子log 值拆成 整數＋[0,1) 小數結論
25050×0.3010＝15.0515＋0.0516 位數，首位 1（0.05 < log 2）
34040×0.4771＝19.08419＋0.08420 位數，首位 1
62020×0.7781＝15.56215＋0.56216 位數，首位 3（log3 ≤ 0.562 < log4）
(13)20−20×0.4771＝−9.542−10＋0.458小數點後第 10 位開始不為 0，首位 2
(0.3)1010×(0.4771−1)＝−5.229−6＋0.771小數點後第 6 位開始不為 0，首位 5（log5 ≤ 0.771 < log6）
易錯陷阱

負數的 log 要拆成「負整數＋正小數」：−9.542＝−10＋0.458，不是 −9−0.542。小數部分一定要落在 0 到 1 之間。

五、應用題

  • 成長／衰減：每期變成 r 倍，n 期後是 rn 倍。「至少幾期才超過（或低於）某值」⇒ 兩邊取 log 解 n，答案無條件進位取整數。注意 r < 1 時 log r < 0，兩邊除以它不等號要變向。
  • 地震規模：log E＝11.8＋1.5M，規模差 ΔM，能量差 101.5ΔM 倍；規模差 1 ⇒ 能量約差 101.5 ≈ 31.6 倍；規模差 2 ⇒ 1000 倍。
  • 已知 log 值求比值：log a＝4.6、log c＝1.6 ⇒ ac＝103；看到「差」的分式要先提公因數 10 的次方。
小撇步

3-1 多項式的運算與應用

一、名詞

  • f(x)＝anxn＋…＋a1x＋a0，an ≠ 0 時：次數 deg f＝n，首項係數 an，常數項 a0＝f(0)。
  • 零多項式（0）不定義次數；非零常數多項式是 0 次。
  • 各項係數和＝f(1)；偶次項係數和＝f(1)＋f(−1)2；奇次項係數和＝f(1)−f(−1)2。
  • 兩多項式相等 ⇔ 同次項係數全部相等。

二、除法原理

核心觀念

f(x)＝g(x)Q(x)＋r(x)，r(x)＝0 或 deg r < deg g。商式與餘式唯一。
次數關係：deg Q＝deg f−deg g。

三、綜合除法

  • 除以 x−a：係數依降冪排好（缺項補 0），第一個係數直接拉下，乘 a 加到下一個，重複，最後一格是餘式。
  • 除以 ax−b：先除以 x−ba 得商 q(x)、餘 r，則 f(x)＝(ax−b)·q(x)a＋r：商要除以 a，餘式不變。
  • 連續綜合除法：對商式重複除以 x−h，由下往上讀餘數，即可寫成 f(x)＝a(x−h)3＋b(x−h)2＋c(x−h)＋d。
    例：x3＋2x2−3x＋5＝(x−1)3＋5(x−1)2＋4(x−1)＋5。

四、餘式定理與因式定理

餘式定理

f(x) 除以 x−a 的餘式＝f(a)。
f(x) 除以 ax−b 的餘式＝f(ba)。

因式定理

x−a 是 f(x) 的因式 ⇔ f(a)＝0。
ax−b 是因式 ⇔ f(ba)＝0。

除以二次式：設餘式 px＋q。例：f(x) 除以 x−1 餘 3、除以 x＋2 餘 −6，則 f(x)＝(x−1)(x＋2)Q(x)＋px＋q，代 x＝1、−2：p＋q＝3、−2p＋q＝−6 ⇒ p＝3、q＝0，餘式 3x。

除以不能分解的二次式（降次法）：求 (x2＋x＋5)5 除以 x2＋x＋1 的餘式：因為 x2＋x＋5＝(x2＋x＋1)＋4，展開後除了 45 以外每一項都含因式 x2＋x＋1，所以餘式＝45＝1024。（口語：在除以 x2＋x＋1 時，x2＋x 可以當成 −1。）

除以 (x−a)2：連續綜合除法兩次，餘式＝c(x−a)＋d。也可令 t＝x−a，丟掉 t2 以上的項。

易錯陷阱
  • 除以 x＋2 要代 x＝−2，不是 2。
  • 除以 2026x＋2026＝2026(x＋1)，餘式是 f(−1)（除式乘上非零常數不影響餘式）。
  • 綜合除法忘了補 0（例如 x3−2x＋1 的 x2 係數是 0）。
  • 除以 2x−1 時，商要再除以 2。

五、插值：已知函數值求多項式

  • 已知根先用因式定理：三次 f 滿足 f(1)＝f(3)＝0 ⇒ 設 f(x)＝(x−1)(x−3)(ax＋b)，再用其他兩個值解 a、b。
  • 已知三點求二次：可設 f(x)＝a＋b(x−x1)＋c(x−x1)(x−x2)，一個一個代就能解；或用拉格朗日形式直接寫出（寫法以課本為準）。
  • 「f(x) 除以 x 的餘式」就是 f(0)。

3-2 簡單多項式函數及其圖形

一、函數

每一個 x 都恰好對應一個 y，就叫 y 是 x 的函數，記作 y＝f(x)。圖形判斷法：任何鉛直線和圖形最多交一點。

二、一次函數 f(x)＝ax＋b

  • 圖形是直線，斜率 a＝f(x2)−f(x1)x2−x1，y 截距 b。
  • 例：f(−4)＝19、f(−1)＝7 ⇒ 斜率 7−19−1−(−4)＝−4，f(x)＝−4x＋3。
  • a＝0 時是常數函數（水平線）。

三、二次函數 y＝ax2＋bx＋c（a ≠ 0）

核心觀念：配方

y＝a(x＋b2a)2＋4ac−b24a，頂點 (−b2a, −D4a)，D＝b2−4ac。

a>0：開口向上，頂點是最低點（有最小值）；a<0：開口向下，頂點是最高點（有最大值）。

  • 頂點式 y＝a(x−h)2＋k；兩根式 y＝a(x−α)(x−β)，對稱軸 x＝α＋β2。
  • 平移：y＝f(x) 向右 h、向上 k ⇒ y＝f(x−h)＋k；向左 h、向下 k ⇒ y＝f(x＋h)−k。
  • 對稱：f(h＋t)＝f(h−t)。例如對稱軸 x＝1 ⇒ f(4)＝f(−2)、f(5)＝f(−3)。

四、最大值與最小值

情況（以 a>0 為例）最小值最大值
定義域是全體實數頂點 k沒有
範圍 [p, q] 且頂點 h 在範圍內頂點 k比較 f(p)、f(q)，離 h 較遠的端點較大
範圍 [p, q] 且頂點在範圍外靠近 h 的端點離 h 較遠的端點

例：y＝x2−4x＋1＝(x−2)2−3，在 0 ≤ x ≤ 5：最小 −3（x＝2），最大 f(5)＝6（5 離 2 比 0 遠）。

例：f(x)＝(x−1)2＋(x＋1)2＋(2x−4)2＝6x2−16x＋18 ⇒ 頂點 x＝43，最小值 223。這種「好幾個平方和」先展開合併成一個二次式再配方。

易錯陷阱

有範圍的最值題，一定要先檢查頂點在不在範圍內；最大值也要比較兩端點，不能只算一端。

3-3 多項式函數的圖形（本次只考圖形，不考不等式）

一、y＝ax3 與 y＝ax3＋px

  • f(−x)＝−f(x)，圖形對稱於原點。
  • y＝ax3：在原點附近很「平」（貼近 x 軸），|x| 大時增長很快。
  • y＝ax3＋px：在原點附近像直線 y＝px；a、p 異號時與 x 軸交三點（0 與 ±√−p/a），同號時只交於原點。

二、一般三次函數的對稱中心

核心觀念

任何三次函數 f(x)＝ax3＋bx2＋cx＋d 都能寫成 f(x)＝a(x−h)3＋p(x−h)＋k，其中 h＝−b3a、k＝f(h)。

圖形是 y＝ax3＋px 平移到以 (h, k) 為中心，所以 (h, k) 是對稱中心：圖形上任兩點若對稱於中心，中心就是它們的中點。

例：f(x)＝x3−6x2＋10x−1，h＝63＝2，連續綜合除法得 f(x)＝(x−2)3＋0·(x−2)2−2(x−2)＋3，對稱中心 (2, 3)。

  • p＝0 ⇔ 圖形可由 y＝ax3 平移得到。
  • 平移不會改變 a 和 p；y＝f(x) 往右 m、往上 n，中心也跟著往右 m、往上 n。
  • 已知 g(x)＝f(x＋2) 的中心 (−1, 7)，則 f(x)＝g(x−2) 的中心是 (1, 7)（往右 2）。

三、局部特徵：一次近似

核心觀念

把 f(x) 寫成 f(x)＝a(x−t)3＋b(x−t)2＋c(x−t)＋d。當 x 很靠近 t，(x−t)2、(x−t)3 非常小，所以 f(x) ≈ c(x−t)＋d。直線 y＝c(x−t)＋d 就是 y＝f(x) 在 x＝t 附近的一次近似。

例：f(x)＝x3−3x2＋5x＋1＝(x−1)3＋2(x−1)＋4，f(1.01) ≈ 2(0.01)＋4＝4.02（真值 4.020001）。

若要四捨五入到小數點後第二位，一次近似通常就夠；但二次項係數很大或要求更多位數時，要把 b(x−t)2 也算進去檢查。

四、廣域特徵

|x| 很大時 f(x) 的走勢由首項決定：例如 −2x3＋100x2＋… 在 x 很大時往下（→ −∞）、x 很負時往上。看圖選函數時，先用「兩端的走向」刪選項，再用 y 截距、根的位置判斷。

第 1 題2-2 對數定義

看答案與解析

答案：A

第 2 題高頻考點2-2 位數

看答案與解析

答案：C

第 9 題高頻考點3-2 區間最值

看答案與解析

答案：a＝0、b＝−7；x3−7x＋6＝(x−1)(x−2)(x＋3)

f(1)＝7＋a＋b＝0；f(2)＝14＋4a＋2b＝0 ⇒ 2a＋b＝−7。相減得 a＝0，b＝−7。三根乘積：常數項 6＝−(1)(2)(r) ⇒ r＝−3，第三個因式 x＋3。

a＝0 代表沒有 x² 項，綜合除法要記得補 0：1, 0, −7, 6。

7. 二次函數區間最值（3-2）

什麼時候用

二次函數加上 x 的範圍，問最大、最小值。

  1. 配方：y＝a(x−h)2＋k。
  2. 看頂點 h 在不在範圍內。
  3. 在範圍內：頂點給一個極值（a>0 最小、a<0 最大）；另一個極值比較兩端點。
  4. 不在範圍內：兩端點分別代入比大小。
換你試試 73-2
當 0 ≤ x ≤ 4 時，y＝−x2＋6x−4 的最大值與最小值各為何？
看答案與解析

答案：最大值 5，最小值 −4

y＝−(x−3)2＋5，開口向下，頂點 x＝3 在範圍內 ⇒ 最大 5。端點 f(0)＝−4、f(4)＝4 ⇒ 最小 −4（0 離 3 較遠）。

開口向下時頂點是山頂（最大），最小值跑到離山頂最遠的端點。

8. 三次函數對稱中心與一次近似（3-3）

什麼時候用

問對稱中心、圖形在某點附近像哪條直線、f(2.01) 這類近似值。

  1. h＝−b3a（求近似值時改用題目給的點）。
  2. 用 h 做連續綜合除法，寫成 a(x−h)3＋b′(x−h)2＋p(x−h)＋k（中心時 b′＝0）。
  3. 對稱中心 (h, k)；近似直線 y＝p(x−h)＋k，記得乘開化簡。
  4. 求近似值：代 x−h＝很小的數，高次項幾乎是 0。
換你試試 83-3
f(x)＝2x3−12x2＋20x−3。求 (1) 對稱中心；(2) 中心附近的近似直線；(3) f(2.01) 四捨五入到小數點後第二位。
看答案與解析

答案：(1) (2, 5)　(2) y＝−4x＋13　(3) 4.96

h＝126＝2，連續綜合除法得 f(x)＝2(x−2)3−4(x−2)＋5。中心 (2, 5)，近似直線 −4(x−2)＋5＝−4x＋13。f(2.01)＝0.000002−0.04＋5＝4.960002 ≈ 4.96。

這題的中心剛好就是要求近似值的點，一次展開三個小題全部解決。

常見失分原因

易錯陷阱
  • 位數答成整數部分（少 1 位）；負的 log 沒有借 1，小數第幾位答錯。
  • log 5、log 6、log 9 沒有用 log2、log3 換算；把 log(a＋b) 拆開。
  • 衰減題 log 0.8 是負的，除過去沒變號；「至少幾年」沒有無條件進位。
  • 除以 x＋2 代成 x＝2；除以 2x−1 時商沒有除以 2。
  • 綜合除法缺項沒補 0。
  • 區間最值沒檢查頂點是否在範圍內，或只比一個端點。
  • 三次函數中心用成 −b/(2a)；近似直線 p(x−h)＋k 沒乘開或乘錯。
  • 寫了不考的不等式題浪費時間（若考卷真的出現，以老師公告為準）。
  • 多選題漏選、答案卡劃記錯位。
